# i18n 约定（FateQuill / 命笔）

> 本文档描述界面双语化（i18n）的命名空间、资源布局、回退与持久化约定。
> 归属阶段：v0.1.0-stage-01（T8）。技术栈：i18next + react-i18next。

## 1. 定位

- 本项目 i18n 为**界面双语化，非内容本地化**（大计划 §1.5，约束 C-11）：仅外壳/按钮/菜单等界面文案参与翻译；**创作向内容不翻译**（见 §6）。

## 2. 初始命名空间清单

| 命名空间   | 职责                                      | 资源文件                           |
| ---------- | ----------------------------------------- | ---------------------------------- |
| `common`   | 通用/外壳文案（应用名、通用动作、语言等） | `src/locales/{lang}/common.json`   |
| `editor`   | 编辑器相关文案（占位，后续阶段填充）      | `src/locales/{lang}/editor.json`   |
| `settings` | 设置相关文案（占位，后续阶段填充）        | `src/locales/{lang}/settings.json` |

> `common` 为默认命名空间（`defaultNS`）。新增命名空间须同步更新本文档。

## 3. 资源布局

- 目录结构：`src/locales/{zh-CN,en}/{namespace}.json`。
- 支持语言：`zh-CN`（默认）、`en`；由 `supportedLngs` 限定。
- **回退规则**：`fallbackLng = "zh-CN"`。**新增文案应同时提供 zh-CN 与 en；若 en 缺失，运行时自动回退 zh-CN**（例如 `common.onlyZh`）。

## 4. 键命名规则

- 使用 **camelCase**，按语义分组，组内嵌套层级由命名空间文件承载。
- 例：`common.appName`、`editor.toolbar.save`、`settings.appearance.theme`。
- 避免在键名中重复命名空间前缀。

## 5. 语言切换与持久化

- 初始化位于 `src/app/i18n.ts`（app 装配层）；在 `src/app/main.tsx` 渲染前 `import "./i18n"`。
- 语言检测顺序：`localStorage` → `navigator`；检测结果缓存至 `localStorage`。
- **持久化 key**：`fatequill.lang`。
- **`<html lang>` 同步**：初始化时即同步（含 `typeof document !== "undefined"` 守卫，兼容 jsdom/SSR）；切换语言时同步更新。
- 切换器组件：`src/ui/LanguageSwitcher.tsx`（通用 UI 层）。

## 6. 不本地化范围（C-11）

以下**创作向内容不翻译**：生成 prompt、风格库、作品设定、正文内容等。i18n 仅覆盖界面外壳文案。
