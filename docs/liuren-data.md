## 二、校对口径（约定）

1. **十二天将顺布序**：贵人 → 螣蛇 → 朱雀 → 六合 → 勾陈 → 青龙 → 天空 → 白虎 → 太常 → 玄武 → 太阴 → 天后（六吉六凶各半）。
2. **十二宫**：地盘固定 `子…亥`；各支的**月将名**取通行表述（子—神后、丑—大吉、寅—功曹、卯—太冲、辰—天罡、巳—太乙、午—胜光、未—小吉、申—传送、酉—从魁、戌—河魁、亥—登明）。
3. **月将 / 时辰 / 日干支均为输入而非计算**：`月将` 由用户在下拉中选择（选项展示「月将名（支）」），**不予推算**；
   **`dayGanzhi` 必填**（**REV-006 定稿**：四课由「日干支 × 2 + 时支 × 2」构成，缺日干支则四课无据），取**六十甲子**之一（非法 → `{ ok:false, error }` 早返回）。
4. **一课下神取日干寄宫支**：本实现以**寄宫支**参与贼克比较（甲寄寅、乙寄辰、丙戊寄巳、丁己寄未、庚寄申、辛寄戌、壬寄亥、癸寄丑）。
5. **天将布将**：天乙贵人起宫按通行口诀（甲戊庚牛羊 / 乙己鼠猴乡 / 丙丁猪鸡位 / 壬癸蛇兔藏 / 六辛逢马虎）取**昼贵 / 夜贵**；本实现**昼夜口径**为「时辰落 `卯..申` 为昼，其余为夜」；贵人落宫在 `亥..辰` **顺布**、在 `巳..戌` **逆布**。
6. **课体命名**：九宗门名目（贼克 / 比用 / 涉害 / 遥克 / 昴星 / 别责 / 八专 / 伏吟 / 返吟）作为**静态课体表**登记。

## 四、简化口径（**产品定位 = 课体引导，非断卦**）

- **取用顺序**：**先判天地盘特例**（月将 = 时辰 → `伏吟课`，取一课干上神；月将与时支相冲 → `返吟课`，取三课支上神）
  → 再**贼克法**：下贼上优先 → 唯一即取（`贼克课`）；多则取与日干同五行者（`比用课`）；无贼取上克下（同上）；
  俱无 → `昴星课`（取一课干上神）。
- **未细分**：`涉害课`（涉害深浅比较）、`遥克课`、`别责课`、`八专课` **仅登记课体名目**，本实现不据此细分取用；
  上述分支均**不参与**任何自动判定，仅作为引导文本中的课体标注。
- **不断验**：本域不含吉凶断语集与应期规则；引导文本显式声明「**仅为叙事参考，不得违背用户设定约束**」。

## 五、体积影响与版本

- **体积（实测）**：静态常量增量随 `manualChunks` 进入 `orchestration` 分组——stage-12 实测 `orchestration-*.js` 由 59.77 kB → **76.17 kB**（含大六壬白文数据，以及大六壬/全自动编排代码），
  **零新增第三方依赖**（无历法库、无校验库）；`> 500 kB` 体积警告**不复现**（详见 `docs/build-size-report.md` §九）。
- **版本**：`LIUREN_DATA_VERSION = "1.0.0"`；数据或框架变更时递增并在本文件「校对口径」同步说明。
- **IPC**：**无新增 Rust 命令**（前端静态数据 + 纯函数，同 stage-09 易经范式）。
