# 六十四卦数据说明（`src/data/iching/`）

> 归属阶段：v0.3.0-stage-09（T1）｜数据版本：**`ICHING_DATA_VERSION = "1.0.0"`**（`src/data/iching/hexagrams.ts`）
> 落点：`src/data/iching/`（**只读静态 TS 常量**；无新迁移、无 IO）。

## 一、数据来源与许可

- **来源**：《周易》**经文白文**（64 卦辞 + 384 爻辞），取自**公有领域**传统通行本文字。
- **不含今人译注**：不收录任何仍在版权保护期内的今人注释/翻译/研究文本。
- **许可**：经文本身为公有领域，可自由使用与再分发；本项目对结构化整理（卦序、二进制约定、校验规则）以与项目一致的许可发布。
- **可追溯性**：本文件随代码版本演进（数据变更须同步修订本文件的「校对口径」与「版本」）。

## 二、校对口径（约定）

| 项             | 约定                                                                                         |
| -------------- | -------------------------------------------------------------------------------------------- |
| **卦序**       | **King Wen 卦序** 1~64（连续无缺）                                                           |
| **爻位**       | **自下而上**：`lines[0]` = 初爻，`lines[5]` = 上爻                                           |
| **二进制**     | 6 位字符串，`binary[0]` = **初爻**（下卦最低位）；`1` = 阳爻，`0` = 阴爻                     |
| **上下卦**     | `binary` 前 3 位 = **下卦**，后 3 位 = **上卦**；名称为八卦名（乾/兑/离/震/巽/坎/艮/坤）     |
| **八卦二进制** | 三爻自下而上：乾 `111`、兑 `110`、离 `101`、震 `100`、巽 `011`、坎 `010`、艮 `001`、坤 `000` |
| **爻辞范围**   | **仅六爻**（不含乾「用九」、坤「用六」），故总数恰为 **64 + 384**                            |
| **标点**       | 采用现代通行标点（句读），保留原文用字；异体/通假字以通行本为准                              |

## 三、校验规则（六条，`src/data/iching/validate.ts`）

> 依 **REV-006 裁决**：**不引入任何第三方校验库**（C-08 / 零新增依赖）——改以**手写 TypeScript 类型守卫 + 运行时断言**实现。

| #   | 规则                          | 说明                                                                              |
| --- | ----------------------------- | --------------------------------------------------------------------------------- |
| ①   | 卦数 = **64**                 | `HEXAGRAMS.length === 64`                                                         |
| ②   | 每卦 **6 爻**（合计 **384**） | 逐卦 `lines.length === 6` 且总和 = 384                                            |
| ③   | 卦名**唯一**                  | 68 卦名集合大小 = 64，无重复                                                      |
| ④   | 上下卦组合覆盖 **8×8**        | `upper\|lower` 组合集合大小 = 64；`TRIGRAMS.length === 8`                         |
| ⑤   | **King Wen 卦序连续 1~64**    | 排序后逐一等于 `1..64`                                                            |
| ⑥   | **二进制 ↔ 卦名映射自洽**     | `binary` 为 6 位 0/1；`binaryToNames(binary)` 的上下卦与该卦 `upper`/`lower` 一致 |

- `validateIChing(hexagrams, trigrams)` 返回 `{ ok, errors }`（逐条收集错误，不早退）。
- 单测含**正向**（六规则 + 抽样卦 乾/坤/既济）+ **负向**（重复卦名 / 缺一爻 / binary 不符 / 非法 binary / 卦序缺一）。

## 四、体积影响

- 数据为纯 TS 常量，随主包打包；纳入 `docs/build-size-report.md` 口径跟踪（stage-08 T6）。

- **数据版本**：`1.0.0`（首版；64 卦完整白文 + 六条校验）。
- 变更约定：新增/修订卦辞、爻辞、卦序、二进制约定或校验规则时**递增版本**并在本文件登记变更摘要。
