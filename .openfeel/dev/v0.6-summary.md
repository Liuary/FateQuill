## 三、关键架构与决策（v0.6 落地）

1. **大六壬（方案 b）**：手动月将 + 时辰 + 日干支（**不引历法库**，C-08）；公有领域古籍白文 + 手写守卫校验；`castLiuren` 盘面口径「月将加时顺布 → 四课 → 取用（先伏吟/返吟，再贼克法）→ 三传 → 天将（昼夜贵人顺逆布）」；`dayGanzhi` 必填（REV-006）；`liurenGuide?` 与易经并列可选、可叠加；简化口径显式声明（涉害/遥克/别责/八专仅登记）。零新增依赖 / 无迁移 / 无新 IPC。
2. **全自动创作编排**：**六环节决策规则表**（`decide.ts` 纯函数）；**依赖全注入**（`AutopilotDeps`，编排层不 import `@/ipc`/store）；**复用不重写**（`buildChapterPrompt`/`runExploration`/`evaluateWithFallback`+`rewriteChapter`+`weightedTotal`/`runExtraction`）；进度态 `autopilotStore` 单源。
3. **熔断三层**：预算（`estimateTokens` 累计生成正文长度，未配 → 永不触发）/ 连续失败（K 默认 3）/ 章数（启动新章前判定）；顺序 预算 → 连续 → 章数；触发即停 + `trippedBy`/`trippedDetail` 报告。
4. **迁移 v6 断点续跑**：`autopilot_run`（status/config_json）+ `autopilot_chapter`（state/score/degraded_reason/attempt，**`UNIQUE(run_id,order_index)`**）；run 起点/每章起点 `running`、每章终点 `done|degraded`、终态 `completed|paused|aborted`；`config_json` 落 `{config,outline}` 供 `resume`；**已完成章不重跑**（`SettledChapter` seed 跳过）。
5. **冲突策略双路径留痕**：默认 `pause`（`status:"open"` + 暂停 + 通知，复用 `trippedBy="conflict"` → `paused` 可续跑）；显式授权 `ignore-continue`（`status:"ignored"` + `action:"ignore"` + 继续）；两路径均经注入端口落 `conflict_record`；`(aId,bId,type)` 去重；「自动忽略」默认关闭（仅显式授权）。
6. **发布工程**：`bundle.targets=["nsis"]` + `webviewInstallMode=downloadBootstrapper`；`scripts/sync-version.mjs`（三处同步）+ `check-version.mjs`（校验）；`gen-licenses.mjs`（`license-checker` 仅 production + MIT 白名单 + 例外登记；Rust `cargo license` 未装则跳过标注）；`release.yml`（verify/bundle/release）。
7. **英文收口**：`i18n-completeness.test.ts`（en ⊇ zh-CN + 命名空间一一对应）+ `i18n-exemptions.ts`（键豁免 + 值豁免「键仍须存在」+ 卫生断言 ≤3）；Vite glob 加载（避 `node:fs` TS2591）。
8. **IPC 计数**：**5 条新命令**（`save/get/list_autopilot_run` + `save/list_autopilot_chapter`）；计数（§8.1 51→56 / 全仓 53→58）**与实现同提交**（REV-007 占位声明范式）；零新增 runtime 依赖（`license-checker` 仅 dev）。
