## 一、里程碑状态（M1）

> **M1 判定（roadmap）**：新建作品 → 建卷/章 → 编辑正文 → AI 生成一章并**流式插入** → 保存设定卡 → 重启后数据完好。

| 层 | 内容 | 状态 |
|----|------|:----:|
| **数据层** | Rust 集成往返测试（生成插入后 `update_chapter` → 重新 `get_chapter`：content/html/word_count 一致） | ✅ 通过（`cargo test` 42/42） |
| **UI 层** | Vitest mock 全链路（建书→建卷章→mock 生成流→模式 A 直插→存设定卡）+ C-03 Profiler 断言 | ✅ 通过（Vitest 35 文件 133/133） |
| **真机层** | 真实 Tauri 窗口人工协验（冒烟检查单 / 性能实测 / 真实 Key） | ⏳ **4 项待办** |

**结论**：**v0.1 代码层与自动层达成 M1**（5 阶段全部归档、端到端链路以自动化测试可判定闭合）；**真机层人工协验待办**，闭合后 M1 方可标记完成（REV-009 与 stage-04 REV-014 一并 closed）。

## 二、五阶段交付

| 阶段 | 主题 | 核心交付 | 测试基线 |
|------|------|----------|----------|
| **stage-01** | 工程脚手架与工程化基础设施 | Tauri 2 + React 19 + Vite + TS(strict) + Tailwind v4 + shadcn（源码型）+ i18next 骨架；目录分层与 `@/*` 别名；ESLint/Prettier/Vitest/cargo test；windows-latest CI；IPC `ping` 通道 | DoD 11/11 |
| **stage-02** | 核心领域模型与本地存储 | SQLite schema + 内置迁移（单一 SQL 来源）；领域模型（作品/卷/章/设定卡/角色占位）+ 不变量；三段式仓储（接口→IPC 实现→Rust 命令）；28 IPC 命令（25 CRUD + 3 ordering）；IPC 错误结构与统一事务入口 | cargo 28/28、Vitest 36/36 |
| **stage-03** | AI 编排引擎骨架与模型配置 | 可插拔 Provider/Agent/Pipeline 注册表；**Rust 侧 provider 无关 SSE 中继 + 前端自研适配器（ADR-001，无 Vercel AI SDK）**；Channel + requestId + AbortHandle；keyring 密钥链；迁移 v2 模型配置；设置页；流式消费工具（`subscribeChunks`/节流） | cargo 41/41、Vitest 63/63 |
| **stage-04** | 编辑器基础 | Tiptap 3.31.4 章节文档（一章一实例 C-01）+ Markdown 往返；卷→章大纲树（dnd-kit）；`content_format='html'` 零迁移；自动保存（防抖 800ms + flush 三时机 + `chainRef` 串行链）；**T8 AI 增量插入接口 `EditorController`**（撤销 newGroupDelay 合并 + IME DOM 监听）；应用外壳/选书 | Vitest 110/110、cargo 41/41 |
| **stage-05** | 单 Agent 章节生成 + 设定卡（**闭环终点**） | **模式 A 流式直插（ADR-002）**：`subscribeChunks`→节流→`EditorController.appendChunk`；生成面板仅状态；`generationStore`（不持正文、双 store 隔离）；上下文装配预算与裁剪序 + 提示模板版本化；第三栏「生成/设定卡」tab + Key 引导；停止/失败状态机收敛 + 草稿保留；真机冒烟检查单 | cargo 42/42、Vitest 133/133 |

**架构主线**：编排引擎可插拔（Provider/Agent/Pipeline 注册表 + 注册一行扩展）｜密钥零下发（Rust keyring 注入授权头）｜表现层高性能（编辑器单一事实源 + 一章一实例 + 零 React 重渲染）。

## 四、v0.2 衔接建议

1. **质量闭环（P0，stage-06/07）**：多维审查流水线（剧情/世界观/合规/真人感四维 + 加权评分 + 重写回路）+ 去 AI 味研究子系统 v1（多模型对照、AI 味素材标注采集）——去 AI 味为产品差异化内核，与主线并行推进。
2. **基础设施补强**：① 评估引入 **tauri-driver**（真实端到端自动化，替代/补充手测）；② `manualChunks` 分包 editor/orchestration（chunk 体积基线已实测）；③ 真实 WebView 性能实测纳入常规回归。
3. **接口复用**：生成上下文装配（`ChatOptions` + 模板版本化）与 `generationStore` 已预留 **skill 注入锚点**（`CHAPTER_GENERATION_PROMPT_VERSION`）与多步 Pipeline 组合签名，stage-06/07 直接扩展，核心契约零改动。
4. **可用性复盘**：v0.1 五个阶段交付后应有一次**可用性复盘**（roadmap 备注），据此微调 v0.2 及之后范围。

## 五、关键决策留痕（ADR）

- **ADR-001（accepted）**：AI 调用层 = Rust 侧 provider 无关 SSE 中继 + 前端自研协议适配器；v0.1 不引入 Vercel AI SDK（密钥零下发、可取消流式通道）。
- **ADR-002（accepted）**：生成内容落地交互 = **模式 A 流式直插编辑器**；生成面板仅承载状态，不设预览（兑现 stage-04 T8 投资，M1 措辞一致）。
