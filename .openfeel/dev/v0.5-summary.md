**结论**：**v0.5 代码层与自动层达成 M5**——长程设定自洽链路以自动化测试可判定闭合（`cargo test` **59/59**、Vitest **587/587**、114 文件）；**真机与语义层人工协验待办**，不影响结构判定。

- **「冲突可检出、可处置、分级影响注入、暗线保密」**：L1 规则（零幻觉）+ L2 语义（建议非结论）→ `conflict_record` 落库 → 四动作处置；`selectInjectableCards` 白名单 `{main,short}` **恒排 `dark`**（装载侧硬隔离，断言守护）。

## 三、关键架构与决策（v0.5 落地）

1. **四级分级模型（与 `kind` 正交）**：`main`（主线，硬约束）/ `dark`（暗线，硬约束且**不注入正文**）/ `short`（短线，软约束，可转正/过期）/ `temp`（临时，仅提示）。`kind`=内容类型、`tier`=叙事层级，**两维独立**，不扩 `kind` 值域。
2. **持久化（迁移 v5）**：`setting_card.tier` 加列（`CHECK` 四级、`DEFAULT 'short'` 保守、SQL 层过滤）+ `conflict_record` 表 + 索引；`update` 缺省 `COALESCE(?, tier)`（保留既有分级不重置）；命令数不变（`setting_card` 五命令签名扩展）。**不含**版本池快照持久化（stage-08 REV-009 独立跟踪）。
3. **自动归档抽取器**：**手动「归档本章」** → LLM 抽取 `{name,kind,suggestedTier,content,evidence}` → **`evidence` 原文回查**（规范化空白子串断言，不匹配剔除，防幻觉）→ **名称精确去重**（别名/语义相似 v0.5 显式不做）→ 候选入**会话内存待确认队列**（不入库直达）→ 用户确认后 `save_extracted_settings` **事务批落库**（任一非法全回滚）。
4. **一致性引擎（两级校验）**：**L1 规则**（纯函数、离线、零幻觉——实体闭集=卡标题 + 同句出现 + 生死/时间线/数值断言，宁缺毋滥）+ **L2 语义**（经 provider，`advisory: true` **建议非结论**，失败降级 `uncertain`）；`toConflictReport` 仅把 `contradiction` 转 `semantic` 并去重；冲突记录落库 `conflict_record`。
5. **冲突处置（四动作）**：`{change_tier, edit(跳转 + verbatim 定位), false_positive(反馈闭环), ignore(留痕)}`；`persistNew` 按 `(aId,bId,type)` 去重落库。
6. **暗线硬隔离（本阶段硬要求）**：`selectInjectableCards` 白名单 `{main,short}`，**恒排 `dark`**（无开关可绕过）；`isInjectableTier` 三态边界（白名单 true / 历史未标注默认 true / **未知值 fail-closed false**）；三处装载点（`buildExplorationOptions`/`buildChapterGenerationOptions`/`useSceneContext`）可选参数扩展，**不回改 stage-10 契约**；`PROMPT_BUDGET` 结构不变。
7. **误报率可验收**：自建 ≥3 章预埋冲突标注样本集 + `ground-truth.json`；`MISREPORT_THRESHOLD=0.2`（占位待拍板）；锚点断言（报出 3 / 误报 0 / 漏报 0）+ 召回断言防「零报出伪通过」。
8. **与 stage-06 评审边界**：一致性引擎 = **设定 vs 设定**（设定库内冲突）；四维评审「世界观」= **正文 vs 设定**（文本质量）——职责切分、同一 rubric 引用（`docs/review-rubric.md` §4.2）。
9. **IPC 增量**：6 条新命令（归档批落库 1 + 冲突 CRUD 5）；计数与实现**同提交**更新（§8.1 45→51 / 全仓 47→53，双口径定义）；零新增依赖。

## 五、v0.6 衔接建议

1. **术数扩展 + 全自动创作主线（M6，stage-12）**：**大六壬**（stage-09 显式排除）+ 全自动创作 + MIT 开源发布（英文版收口）——卦象系统（stage-09）已建立「可选可关 + 静态数据 + 引导契约」范式，大六壬按同范式接入；设定分级（本阶段）为「全自动创作」提供**结构化设定供给与自洽护栏**。
2. **一致性深化**：① **误报率阈值 X 拍板**与 L2 语义核验回填；② 去重升级（别名/语义相似，超越当前名称精确匹配）；③ 冲突处置留痕缝隙闭合（REV-009）；④ 一致性引擎与全自动创作的实时闭环（生成前校验 + 生成后归档）。
3. **台词评审维度子集（REV-007）**：为台词片段提供「剧情/世界观」维度子集或 UI 勾选（归属于 stage-12 / 人工协验批处理）。
4. **基础设施补强**：① **采纳/合并快照持久化**（stage-08 REV-009 路线）；② 引入 **tauri-driver**（真实端到端自动化，替代/补充手测）；③ 真实 WebView perf 纳入常规回归。
