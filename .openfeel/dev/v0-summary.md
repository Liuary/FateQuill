# FateQuill v0 系列整体总结（12 阶段全览 / 里程碑 M1~M6）

> 生成：2026-10-10（由 openfeel-archiver 随 v0.6.0-stage-12 归档产出）｜范围：**v0 系列全部 12 阶段（v0.1.0-stage-01 ~ v0.6.0-stage-12）**

> **性质**：v0 系列是 FateQuill（命笔）首发系列，交付一款**可用的开源 AI 小说创作桌面应用（MIT）**。

## 一、系列概览

**定位**：Tauri 2 + React 19 桌面应用，以**多 Agent 编排**辅助创作者完成长篇小说创作，并把**「去 AI 味」作为可研究、可积累的学术内核**（独立子系统）。
**设计主线**：**编排引擎可插拔 + 表现层高性能 + 去 AI 味独立成系 + UI 中英双语（创作能力仅面向中文市场）**。
**开发方式**：**纯 AICoding**（用户不手写代码，全部由 OpenFeel 流水线完成）。

**系列成果**：12 阶段全部归档，**里程碑 M1~M6 的代码 / 自动层均达成**（以自动化测试可判定闭合）；**真机 / 语义层统一人工协验批次**（BLOCKED 18 项）待闭合；**发布动作（tag/Release）待用户执行**。

## 三、里程碑达成状态（M1~M6）

> **判定口径（硬性）**：两层判定——**「代码 / 自动层」**（随阶段归档 + 门禁证据，已达成的引用证据）与**「真机 / 语义层」**（人工协验，AI 不可替代）。**AI 不代判「正式达成」**：真机 / 语义层一律记「待协验批次闭合」，里程碑「正式达成」由用户 / 协验批次完成。详见 `clearance.md` §三。

| 里程碑 | 版本 | 判定标准（大计划 §4） | 代码 / 自动层 | 真机 / 语义层 |
|--------|------|----------------------|:-------------:|:-------------:|
| **M1** 最小可用闭环 | v0.1（stage-01~05） | 建作品→建卷/章→编辑→AI 生成并流式插入→存设定卡→重启不丢 | ✅ **达成** | ⏳ 待协验批次 |
| **M2** 质量闭环 | v0.2（stage-06~07） | 多维审查打分 + 自动/手动重写；去 AI 味素材库可采集、标注、导出 | ✅ **达成** | ⏳ 待协验批次 |
| **M3** 创造引导 | v0.3（stage-08~09） | 多温度并行推演产出可对比分支；易经卦象映射剧情走向并收敛到用户设定 | ✅ **达成** | ⏳ 待协验批次 |
| **M4** 多声部 | v0.4（stage-10） | 主要角色各自独立 Agent 生成台词，旁白与对话可分离创作与合并 | ✅ **达成** | ⏳ 待协验批次 |
| **M5** 一致性 | v0.5（stage-11） | 设定自动分级归档，新设定与旧设定冲突可检出并提示 | ✅ **达成** | ⏳ 待协验批次 |
| **M6** 发布 | v0.6（stage-12） | 大六壬可选、全自动创作可跑通、开源仓库可构建发布 | ✅ **达成（代码/自动层）** | ⏳ 待协验批次（#13~#18） |

**结论（如实）**：**M1~M6 的代码 / 自动层均已达成**（各阶段归档 + 门禁证据）；**真机 / 语义层全部待协验批次闭合**（含 M6 的 6 项）。**「M6 正式达成」的前置** = 18 项 BLOCKED 闭合 + 用户确认。

## 四、架构演进主线（v0.1 → v0.6）

- **骨架（v0.1）**：可插拔编排引擎（Provider/Agent/Pipeline 注册表）+ 密钥零下发（Rust keyring 注入授权头）+ 表现层高性能（编辑器单一事实源 + 一章一实例 + 零 React 重渲染）+ **模式 A 流式直插**（ADR-002）。
- **质量与学术内核（v0.2）**：四维评审（LLM-as-judge + 规则引擎）+ 重写回路；**去 AI 味研究子系统**（采样 → 交叉 → 标注 → 素材库 → skill → 回注）——产品差异化内核。
- **创造引导（v0.3）**：多温度并行推演 + 克制收敛 + 采纳安全网；易经卦象**可选可关**（静态数据 + 引导契约）——确立「术数引导可选可关 + 静态数据 + 引导契约 + 关闭零副作用」范式。
- **多声部（v0.4）**：每角色独立 Agent（persona 契约）+ **上下文隔离白名单防串味** + 合并双路径。
- **一致性（v0.5）**：四级设定分级 + 归档抽取（`evidence` 回查）+ L1/L2 校验 + **暗线硬隔离** + 冲突处置落库。
- **发布打磨（v0.6）**：大六壬（并列可选）+ **全自动创作可续跑**（决策规则表 + 熔断三层 + 断点 v6 + 冲突策略）+ 发布工程（打包/许可/版本/Release）+ 英文收口。

**贯穿范式（跨阶段复用）**：① 会话内存 store（独立 `create` + `orderIndex` 恒连续 + 单例共享）；② 可选注入参数（缺省零副作用，`toEqual(baseline)` 断言）；③ 破坏性动作「确认门 + 无损路径 + 强制回滚点」；④ 状态单源（禁多份 `useState`）；⑤ 生产可达性核验（生产调用非零 + 挂载/落库断言）。
