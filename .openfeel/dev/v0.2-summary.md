## 三、关键架构与决策（v0.2 落地）

1. **四维评审机制**：剧情/世界观/真人感 = LLM-as-judge（经 `ModelProvider` **非流式收口**，温度 0）；合规 = **规则引擎**（本地词表/正则，无 Token、可单测）+ 可选 LLM 复核；`evaluateWithFallback` 有限重试 + 降级不抛穿（`DEGRADED_SCORE`）。
2. **加权择优与版本池**：`weightedTotal` 归一 0–100（缺维/零权不参与）；**会话级（内存）版本池**（初版 + 重写轮次）；采纳整章替换 `EditorController.replaceContent(html)`（单条撤销，前端命令面非 IPC）。
3. **重写回路**：失败判定 = 加权总分 < 阈值；`triggerDims = failedDims \ {compliance}`（合规仅人工裁决）；上限 2、反馈注入、**产物入池不自动替换正文**。
4. **去 AI 味闭环**：采样（`MaterialCandidate` 内存候选）→ 交叉（verbatim 引文精确交集，命中 ≥2 高置信 / =1 待确认，**不入库直达**）→ 标注（受控枚举 + verbatim 定位 + `sourceType` 三通道透传）→ 素材库（唯一权威 `excerpt` + 引用防护删除）→ skill（DB 载体 + id 引用 + 版本）→ 回注（system 注入，向后兼容）。
5. **持久化**：迁移 v3 `review_record`（审查记录）+ 迁移 v4 `0004_material_skill.sql`（`material` + `skill_entry`，7→9 表幂等）；均走 stage-02 迁移纪律（`include_str!` 单一来源 + `_sqlx_migrations` 幂等）。
6. **跨阶段扩展**：stage-07 扩展 stage-05 装配器 `ChapterPromptInput.skills?`——**缺省行为完全不变**（stage-05 既有测试回归通过）；加载失败静默降级不注入。
7. **防御性模式**：引文为键规避 offset 幻觉；三通道 `sourceType` 单一来源 + 按来源透传（禁写死）；删除引用防护（JSON 冗余引用结构化精确判定）；**UI 接线验证**（生产调用非零 `rg` 断言，防纯函数/契约测试全绿掩盖「功能无入口」——REV-018 / BUG-001）。
8. **ADR 支撑**：ADR-001（AI 数据面 Rust SSE 中继 + 自研适配器，密钥零下发）与 ADR-002（模式 A 流式直插）在 v0.2 提供的编排/流式/装配基座上直接扩展，**核心契约零改动**。

## 五、v0.3 衔接建议

1. **创造引导主线（M3）**：stage-08 多温度并行推演 + stage-09 易经卦象系统——v0.2 的 `Pipeline`/装配器/去 AI 味 skill 注入已就绪，多分支产出可复用评审择优。
2. **去 AI 味深化**：① T6 度量从「小样本雏形」放大到**统计显著性验证**（真实数据回填后）；② 交叉判断评估**模糊对齐**（当前 verbatim 精确交集，v0.2 接受召回损失）；③ skill **自动归纳**（当前需人工参与）。
3. **基础设施补强**：① 评估引入 **tauri-driver**（真实端到端自动化，替代/补充手测）；② `manualChunks` 分包 editor/orchestration/research（chunk 基线已实测）；③ 真实 WebView perf 纳入常规回归。
4. **接口复用**：生成装配（`ChatOptions` + 模板版本化 + `skills` 注入）与 `reviewStore`/`researchStore` 会话态、`material`/`skill` 数据资产已预留扩展点，v0.3 直接复用，核心契约零改动。
5. **可用性复盘**：v0.1+v0.2 交付后应有一次**可用性复盘**（roadmap 备注），据此微调 v0.3 及之后范围。
