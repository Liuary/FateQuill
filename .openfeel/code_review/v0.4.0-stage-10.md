## 二、核心结论与经验

1. **多声部运行机制定稿（REV-001 high）**：① 场景上下文四构成（设定卡 + 前章末尾/当前章 + 用户场景指令 + 公共对话历史 `[{speaker,content}]`）；② 轮次**用户主导**（选中角色 → 生成 → 追加历史 → 可反复；导演式留待后续）；③ **上下文白名单**（本人 persona 完整 + 公共场景 + 公共对话历史；不含他人 persona 全文，可含公开身份一行摘要）；④ **串味判据可判定化**（A 秘密 X → B prompt 不含 X 的装配断言）；「符合人设」自动判据 = prompt 构造正确性，语义符合度走 stage-06 人工协验。
2. **角色数据与 persona 契约（REV-002 high）**：**零迁移方案 A**——`character.profile` JSON 最小字段 `{identity,personality,speechStyle,goal,extra,major?}`；`buildCharacterAgentPrompt`（persona 完整注入本人 Agent）；旁白 Agent 仅 system 差异；**stage-11 边界显式化**（交付 persona 装配输入契约，stage-11 在其上结构化不回改）；CRUD 落点 `src/features/characters/`（复用既有 Character 五命令）。
3. **产物形态与合并算法（REV-003 medium）**：条目结构五字段（`kind: dialogue|narration` + `orderIndex`）；`dialogueStore` 会话内存（同 stage-08 范式）；**格式单一规范**（`<p class="dialogue|narration">`，样式 CSS 承担）；**合并双路径复用 stage-08 REV-007 范式**（主「新建下一章草稿」无损 / 次「替换当前章」确认 + 强制入池快照 + 单撤销，`Ctrl+Z` 归次路径）。
4. **IPC/持久化/成本（REV-004 medium）**：character 五命令实测齐备 → **零 IPC 增量**；对话条目 = 会话内存 + 合并落库（方案 A）；**迁移 v5 = 不新增**；成本复用 stage-08 `estimateCost`（参与角色数 × 输出上限，启动前显示）+ `profile.major` 过滤。
5. **C-07/C-11 可判定性恢复（REV-005 low）**：任务表补「交付物路径 + 可判定验收」两列；i18n `characters`/`dialogue` 双命名空间；遗留处置四点（stage-08 REV-009 沿用安全网范式衔接 / REV-010 复用语义归属 / **stage-09 REV-009 并入首 op chore 清理** / v0.2·v0.3 BLOCKED 跟踪）；审查衔接（台词可选接 stage-06、合并后章节走既有评审、rubric 互认登记）。
6. **杂项（REV-006 low）**：`DialogueAgentInput` 由「无消费的定义」接线为 `registerCharacterAgent` 实际入参（**单一来源**）；`iching-injection.integration.test.ts` 文件头注明组合回归用途。
7. **BUG-001（medium，修复闭环）**：**「生产端最小占位未替换为完整实现」**——`useDialogue` 本地最小 `buildPublicContext`（op-003 占位）与 `context.buildPublicContext`（op-006 完整装配，**生产零调用**）**同名重名**；场景上下文生产仅落地 1/4。修复 = **删除本地最小实现改调共享函数（单源）** + `useSceneContext`（设定卡 + 前章末尾）+ 面板补场景指令输入；补「**生产调用非零**（spy 真实实现）+ **四块入实际 options** + 空输入零副作用」三断言。修复 commit `311dd63`，独立回归探针（真实 `DialoguePanel` 生产路径）复验通过。
8. **防串味独立探针**：验收以唯一标记走真实生产路径复核（角色 A 私有秘密/目标不进角色 B 的 system+user；公开身份摘要正确；`toCharacterOptions` 生产入口安全），**不复用实现方用例**。
