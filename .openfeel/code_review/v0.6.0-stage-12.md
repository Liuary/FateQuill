## 二、核心结论与经验

1. **全自动运行机制定稿（REV-001 high，本阶段最大工程风险）**：**六环节决策规则表**（推演=大纲+多温度择优复用 stage-08 / 生成=大纲+前置章单次 / 审查=四维阈值复用 stage-06 `passThreshold` / 重写=≤N 默认 2 + 反馈注入 / 仍不达标=`degraded` 降级收录不阻塞 / 归档=每章自动一致性抽取复用 stage-11）；**冲突策略双路径**（默认「暂停+通知」/ 显式授权「自动 `ignored` 继续」，**两路径均留痕**）解决「无人值守 × 用户裁决」核心矛盾；**熔断三层**（预算 / 连续失败 K=3 / 章数，触发即停出报告）；**断点持久化 = 迁移 v6**（对照 stage-08 会话内存局限正确升级——无人值守**必须可续**）；可判定验收（≥3 章大纲→≥3 章产出→每章过阈或 `degraded`→零人工交互断言）。
