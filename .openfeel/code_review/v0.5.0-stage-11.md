## 二、核心结论与经验

1. **设定分级模型定稿（REV-001 high）**：四级 `main`/`dark`/`short`/`temp`（判定标准 / 生命周期 / 冲突严格度三维定义）；**与 `SettingCard.kind` 正交**（`kind`=内容类型、`tier`=叙事层级，**不扩 kind 值域**）；**迁移 v5** `setting_card.tier` 加列（`CHECK` 四级、`DEFAULT 'short'` 保守，SQL 层过滤优于 JSON 扫描）；装载侧过滤衔接（不回改 stage-10 契约）。
2. **自动归档抽取器定稿（REV-002 high）**：**LLM 抽取 + `evidence` 原文回查**（防幻觉硬闸）+ **名称精确去重**（别名/语义相似 v0.5 显式不做）+ **手动「归档本章」** + 候选**不入库直达**（会话内存待确认队列）。`runExtraction` 返回契约定稿 `{ok, candidates, error?}`（失败不抛穿、零命中合法空态）。
3. **一致性引擎定稿（REV-003 high，本阶段最大可行性风险）**：**L1 规则**（结构化断言比对，零幻觉/零成本，宁缺毋滥）+ **L2 语义**（LLM `advisory: true` **建议非结论**，失败降级 `uncertain`）；冲突报告 `{aId,bId,type,evidence,severity}` 定稿；**DoD 从「≥20 章不可判定」修订为可验收**——阈值显式约定（`MISREPORT_THRESHOLD=0.2` 待拍板）+ **≥3 章预埋冲突标注样本集**（复用 stage-08 T6 范式）+「20 章长程」降级为持续收集；与 stage-06「世界观」评审边界切分（设定 vs 设定 / 正文 vs 设定，同一 rubric 引用）。
4. **注入策略与暗线保密（REV-004 medium）**：注入白名单 `{main, short}`，**恒排除 `dark`**（暗线泄露=剧透事故，硬隔离）；预算关系声明（不改 `PROMPT_BUDGET`）；单测级对比验证。
5. **冲突处置与 IPC/持久化（REV-005 medium）**：四动作 `{change_tier, edit(跳转+verbatim 定位), false_positive, ignore}`；抽取候选=会话内存、**冲突记录落库 `conflict_record`**（跨会话留痕）；IPC 据实盘点（**6 新命令**）。
6. **C-07/C-11 范式恢复（REV-006 low）**：任务表两列（交付物路径 + 可判定验收）；i18n `consistency`；文档回写；**遗留处置**（stage-10 REV-007 归属 + **stage-08 REV-009 × v5 联动决策：v5 不纳入快照持久化**）；待拍板 5 项；REV 自查表 6/6。
7. **IPC 计数时序错位（REV-007 medium，closed）**：首个 chore op 预写终态计数（51/53）会造成多个提交窗口文档虚高（**stage-02 REV-013 基数漂移复发**）→ 改**占位声明**（本 op 不改数值）+ 计数**与实现同提交**（op-003：45→46；op-005：46→51）+ 双口径定义 + 防回归断言。
8. **杂项（REV-008 low）**：注入行为变更声明（v0.5 起 `dark`/`temp` 移出 prompt，存量默认 `short` 仍注入）；`runExtraction` 失败形态细化。
