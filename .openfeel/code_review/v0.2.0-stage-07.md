## 二、核心结论与经验

1. **持久化资产必须先定稿迁移（REV-001 high）**：T4 素材库 / T5 skill 库是两大持久化资产，plan v1 完全未提「迁移」且载体未定。定稿：迁移 v4 `0004_material_skill.sql`（插件纪律 + 幂等 7→9）+ `material` 表（`excerpt` 唯一权威 / `position_json` 仅上下文 / 三值 `source_type`）+ `skill_entry` 表（**载体=DB 表**）+ 素材→skill 以 `source_material_ids_json` **id 引用**（避免重复存储）。
2. **「无限制」语义须四点定稿（REV-002 high）**：采样模式 = **不触发审查 / 不自动保存 / 无预算裁剪 / 不进正文不落 chapter**，且**跳过合规拦截**（样本纯净）；配置来源=全部 `model_config` 勾选 ≥1；调度=串行逐模型；产出=素材候选。
3. **交叉合并核心难点以「引文为键」规避（REV-003）**：LLM 返回 offset 不可靠 → 以 **verbatim 引文精确交集**为键，命中 ≥2 高置信 / =1 待确认，**不做模糊对齐**；结果入**待确认队列不入库直达**（避免模型误判污染素材库）。
4. **skill 注入是跨阶段修改，须显式声明（REV-004）**：扩展 stage-05 装配器 `ChapterPromptInput.skills?`（拼入 system，预算桶 ≤500），**缺省向后兼容**（stage-05 既有测试回归必过）+ 两层验证（单元 messages 含 skill / 效果 T6 度量）。
5. **定位格式 anti-幻觉（REV-005）**：verbatim 引文 + 前后文 ≤50（前端文本搜索定位），规避 offset 幻觉；标签=受控枚举（`cliche/parallelism/empty/translationese`，版本化）+ 备注。
6. **T6 实验须可复现且学术诚实（REV-006）**：固定样本集 ≥3 篇、同模型温度 0、真人感主指标 + 其余不回退容差、小样本非统计显著性声明。
7. **遗留处置与成本提示（REV-007）**：stage-06 REV-008/011 并入首 op（chore）、REV-009/010 并入 T2 对齐、REV-014 随收口；成本 ∝ 勾选模型数入风险节。
8. **REV-014 perf 无执行主体（REV-008 blocking）**：op-001 推给 op-007，但 op-007 无 perf 步骤 → op-001 步骤 5 承接 perf 回填 + 显式声明执行主体（用户/feel-tester）+ **BLOCKED 登记不得静默跳过**。
9. **IPC 计数链跨 op 自洽（REV-009）**：命令计数 38→41（material +3）→45（skill +4）跨 op 累积，op-007 不得重设基数（stage-02 REV-013 同类漂移复发）。
10. **三采集通道 sourceType 须透传（REV-011 high）**：op-005 写死 `user_manual` 会破坏三通道语义 → 按被标注项自带通道透传（交叉→cross、采样→creation、手选→manual），`CrossJudgeResult` 增通道字段。
11. **JSON 冗余引用删除防护（REV-012）**：`delete_material` 前全表解析引用精确判定，被 skill 引用则拒绝（`FK_VIOLATION` + 引用列表）——以结构化解析取代子串匹配。
12. **待确认队列口径澄清（REV-013）**：`material.status=candidate` 为**预留枚举**（本阶段待确认=会话内存），所有入库写路径均 `confirmed`，消除死枚举争议。
13. **执行主体与防伪造（REV-014/REV-020）**：真机实验由用户/feel-tester 协验，`report.md` 增**数据状态**字段（已回填/待回填，严禁占位分数），与冒烟检查单联动。
14. **功能无入口是高危模式（REV-018 high / BUG-001 medium）**：`extractFlavorExcerpts`/`mergeByExcerpt` 生产零调用 → `multi_model_cross` 通道不可达；`export.ts` 三函数 + `material.remove` 生产零调用 → 素材库读取侧 UI 不可达。**测试通过 ≠ 功能可用**——纯函数/契约测试全绿掩盖「UI 不可达」，须以**生产调用非零 rg 断言**收口（新增 `useCrossJudge` + `MaterialLibrary` 修复）。
