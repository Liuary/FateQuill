# 分期大纲 v0（FateQuill / 命笔）

> 制定人：openfeel-planner ｜ 日期：2026-10-08 ｜ 状态：待 openfeel-reviewer 审查
> 关联：`.openfeel/plan/plan.md`（大计划）、`.openfeel/deps.yaml`（依赖）

## 目标

v0 系列交付一款**可用的开源 AI 小说创作桌面应用（FateQuill / 命笔，MIT 许可）**，在完成最小可用闭环后，逐步叠加「质量审查」「术数引导」「多声部角色」「设定一致性」等能力，
并同期建设**去 AI 味研究子系统**这一学术内核。

设计主线：**编排引擎可插拔 + 表现层高性能 + 去 AI 味独立成系 + UI 中英双语（创作能力仅面向中文市场）**。

## 版本规划与优先级

| 版本 | 主题 | 优先级 | 阶段 | 关键能力 |
|------|------|:------:|------|----------|
| **v0.1** | 最小可用闭环 | P0 | stage-01~05 | 编辑器 + 单 Agent 生成 + 设定卡 |
| **v0.2** | 质量闭环 | P0 | stage-06~07 | 多维审查 + 去 AI 味研究子系统 |
| **v0.3** | 创造引导 | P1 | stage-08~09 | 多温度推演 + 易经卦象 |
| **v0.4** | 多声部 | P1 | stage-10 | 角色独立 Agent 对话 |
| **v0.5** | 一致性 | P2 | stage-11 | 设定分级归档 + 一致性引擎 |
| **v0.6+** | 发布打磨 | P2 | stage-12 | 大六壬 + 全自动创作 + 开源发布（MIT、英文版收口） |

### 优先级取舍原则
1. **先闭环后增强**：v0.1 必须先跑通「创作→生成→审阅→保存」，任何增强能力不得阻塞闭环。
2. **去 AI 味与主线并行**：v0.2 即引入研究子系统，避免其被无限推后；它是产品差异化内核。
3. **术数引导靠后**：多温度推演与卦象为差异化亮点但非闭环必需，排在质量闭环之后。
4. **可插拔优先于功能数量**：编排引擎接口先立住，后续角色/模型/术数均为插件式接入。

## 阶段划分

### v0.1 最小可用闭环（P0）
- **v0.1.0-stage-01** 工程脚手架与工程化基础设施 — Tauri2+React+Vite+TS+Tailwind+shadcn 骨架、构建/测试/CI、**i18n 基建（i18next，中英双语）**。
- **v0.1.0-stage-02** 核心领域模型与本地存储 — SQLite schema、迁移、仓储层（作品/卷/章/设定卡/角色占位）。
- **v0.1.0-stage-03** AI 编排引擎骨架与模型配置 — 可插拔 Agent/Provider/Pipeline + 多 provider 配置 + **Rust 侧 provider 无关 SSE 中继 + 前端自研协议适配器（v0.1 不引入 Vercel AI SDK；ADR-001）**。
- **v0.1.0-stage-04** 编辑器基础 — Tiptap 3.31.4 按章节分文档、WYSIWYG+Markdown、卷→章大纲树（dnd-kit 拖拽）、自动保存（flush/重试）、应用外壳与选书、**AI 增量插入接口**（供 stage-05）。
- **v0.1.0-stage-05** 单 Agent 章节生成 + 设定卡 — **模式 A 流式直插**（ADR-002）、生成面板仅状态、状态隔离（Profiler）、最小闭环。

### v0.2 质量闭环（P0）
- **v0.2.0-stage-06** 审查流水线 — 四维审查（剧情/世界观/真人感 LLM-as-judge + 合规规则引擎）、加权评分与多版本择优、重写回路（上限 2）。
- **v0.2.0-stage-07** 去 AI 味研究子系统 v1 — 多模型无限制创作（采样）、交叉判断（引文交集）、用户标注、素材库（迁移 v4）、skill 库雏形与回注度量。

### v0.3 创造引导（P1）
- **v0.3.0-stage-08** 多温度并行推演引擎 — 同模型多温度并行推演、走向卡分支对比、克制收敛（降权+标注、用户终选）、采纳双路径（新建下一章草稿 / 替换当前章+单撤销）。
- **v0.3.0-stage-09** 易经卦象系统 — 六十四卦 + 爻变建模、映射剧情发展与角色宿命。

### v0.4 多声部（P1）
- **v0.4.0-stage-10** 角色 Agent 多声部对话 — 每角色独立 Agent、旁白/对话分离生成与合并。

### v0.5 一致性（P2）
- **v0.5.0-stage-11** 设定分级归档与一致性引擎 — 主线/暗线/短线/临时分级、自动归档、旧设定一致性校验。

### v0.6+ 发布打磨（P2）
- **v0.6.0-stage-12** 大六壬进阶 + 全自动创作 + 发布打磨 — 可选术数、无人值守创作、MIT 开源发布、**英文版（仅界面基本信息）收口**。

## 里程碑

| 里程碑 | 版本 | 判定 |
|--------|------|------|
| M1 最小可用闭环 | v0.1 | 建作品→建卷章→编辑→AI 生成并流式插入→存设定卡→重启不丢 |
| M2 质量闭环 | v0.2 | 多维审查打分 + 重写回路 + AI 味素材可采集导出 |
| M3 创造引导 | v0.3 | 多温度分支可对比 + 卦象可映射并收敛 |
| M4 多声部 | v0.4 | 多角色独立生成台词，旁白/对话分离 |
| M5 一致性 | v0.5 | 设定自动分级，冲突可检出 |
| M6 发布 | v0.6+ | 大六壬可选、全自动跑通、MIT 开源可构建、英文版基本信息完整 |
