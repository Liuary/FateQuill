## 目标
在 `src/orchestration/review/` 建立 Evaluator 契约（`evaluate(input) → EvaluationResult`）、可注册注册表与评分 JSON 契约/容错降级；类型编译通过、注册/解析（含降级）单测通过。

## 定稿约定（plan v2 REV-001）
- **落点 `src/orchestration/review/`**（复用引擎契约，与 `manual/orchestration/engine.md` 扩展点一致）。
- `EvaluationResult = { score: 0–100; reasons: string[]; findings?: unknown }`。
- **JSON 解析容错与降级**：解析失败 → 有限重试 → 仍失败则**降级**（默认分 + `reasons` 标注「判定失败」），**不抛穿流水线**。
- 注册机制复用 `src/orchestration/registry.ts` 的泛型 `Registry<T>`。
