- [x] 3. `EditorController.ts`：新增 `replaceContent(html)`（**整章替换 = 单条撤销历史**）
  ```ts
  export interface EditorController {
    appendChunk(text: string, options?: AppendOptions): void;
    flushPending(): void;
    replaceContent(html: string): void;   // 整章替换（单条撤销）；appendChunk 追加语义不变
    dispose(): void;
  }
  // 实现：以「解析 html → 整文档替换」的事务（默认入历史）替换；与 newGroupDelay=5000 配合为单条历史
  replaceContent(html) {
    editor.commands.setContent(html, { emitUpdate: true });   // 若 setContent 不入历史，则改用显式 tr.replaceWith 默认入历史（见修正记录）
  }
  ```
  - 测试断言：替换后 `editor.commands.undo()` **一次**即恢复替换前内容。
