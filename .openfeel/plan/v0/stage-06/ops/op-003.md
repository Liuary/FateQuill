## 目标
落地四维评估器：剧情/世界观/真人感 = **LLM-as-judge**（经 stage-03 `ModelProvider`，**非流式收口** + JSON 解析）；**合规 = 规则引擎**（`compliance-rules.ts` 词表可配置，无需 Token + 可选 LLM 复核）；交付 **rubric 文档** `docs/review-rubric.md`（版本化、内联 prompt）与**评审测试样本集**。

## 定稿约定（plan v2 REV-001/REV-004）
- LLM 维经 `provider.stream(ChatOptions)`**聚合完整文本后解析 JSON**（复用 stage-03 适配器，不新增流式 UI）；解析失败由 T1 `evaluateWithFallback` 重试/降级。
- 合规规则载体 `src/orchestration/review/compliance-rules.ts`：结构化类目 + 词表/正则 + 说明 + **版本常量**；内置**初始词表并标注覆盖范围有限**。
- rubric 分档：`0–59 不合格 / 60–79 合格 / 80–89 良 / 90–100 优`；四维子维度：剧情（逻辑连贯/冲突推进/节奏/伏笔呼应）、世界观（设定自洽/术语一致/环境可信）、合规（涉政/色情/暴力/广告/价值观）、真人感（套话密度/句式单调/情感空洞/信息密度）。
- LLM 维测试 = **夹具回放**（`tests/fixtures/review/` mock 响应样本）；合规维**无需 Token** 单测。

  ```ts
  /** 构造 LLM 判定评估器：provider.stream 聚合完整文本 → parseEvaluationJson */
  export function createLlmJudgeEvaluator(opts: { dimension: ReviewDimension; provider: ModelProvider }): Evaluator {
    return { id: opts.dimension, async evaluate(input) {
      const options: ChatOptions = { model: input.model, temperature: input.temperature ?? 0,
        messages: [ { role: "system", content: buildReviewSystemPrompt(opts.dimension) }, { role: "user", content: input.content } ] };
      let full = "";
      for await (const c of opts.provider.stream(options)) full += c.delta;   // 非流式收口（聚合）
      return parseEvaluationJson(full);   // 失败抛错 → 交 evaluateWithFallback 降级
    }};
  }
  ```
