# op-005：重写回路：反馈注入 / 上限 2 / 入池不自动替换（T4）

- **阶段**：v0.2.0-stage-06
- **状态**：done
- **前置**：op-004（T3 版本池 + 评分）
- **负责 Agent**：openfeel-executor
- **最多重试**：3

## 目标
实现「判定 → 重写 → 复审」回路：未通过触发**自动重写（默认开、可关）**，**上限 2 次**、**注入上轮反馈**（未通过维度 `score`+`reasons`）、重写产物**入版本池并自动评分、不自动替换正文**；达上限转人工提示；**合规低分不作为自动重写触发项**（仅人工裁决）。

## 定稿约定（plan v2 REV-005 / REV-004）
- 上限 **2 次自动重写**，达上限转人工（每轮重写前提示）。
- 反馈注入：重写 prompt **结构化注入上轮未通过维度的 `score` + `reasons`**。
- 落地：重写产物**入版本池 + 自动评分**，**不自动替换正文**（用户择优采纳）。
- 开关：自动重写**默认开启**，可在权重配置中关闭。
- **合规低分仅提示人工裁决，不自动重写**。

  ```ts
    provider: ModelProvider; model: string;
    content: string;                       // 初版正文
    evaluators: EvaluatorRegistry;
    weights: ReviewWeights;

  export async function runReviewLoop(opts: ReviewLoopOptions): Promise<{ needsHuman: boolean; rounds: number }> { /* ... */ }
  ```
  - **失败判定**：`weightedTotal(results, weights) < passThreshold`。
  - **自动重写触发维度**：`failedDims = 未通过维度`；`triggerDims = failedDims.filter(d => d !== "compliance")`；**`triggerDims` 为空 → 不自动重写**（合规仅人工裁决），置 `needsHuman=true`。
  - **循环**：`round < maxRounds && autoRewrite && triggerDims.length>0` 时：`buildRewriteMessages`（注入 `triggerDims` 的 score+reasons）→ `rewriteChapter` → 复审 → `onVersion({round+1,...})`；达上限 → `needsHuman=true`。
