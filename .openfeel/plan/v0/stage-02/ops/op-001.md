## 背景（对应遗留 REV）
- **REV-016**：`shadcn` 被置于 `dependencies`。**语义修正（执行期裁决）**：该包并非纯 CLI——`src/index.css:3` 的 `@import "shadcn/tailwind.css"` 在构建期消费它提供的 `@utility`/自定义 variants/keyframes，直接移除会导致 `pnpm build` 失败。正确定位为**构建期依赖** → 按 REV-016 建议中的「移入 `devDependencies`」选项处置。
- **REV-017**：`src-tauri/Cargo.toml` 残留模板默认 `description = "A Tauri App"` / `authors = ["you"]`。
- **REV-018**：`index.html` 静态 `lang="en"` 与默认语言 zh-CN 不一致。
- **REV-019**：① `pnpm-workspace.yaml` 无用途注释；② `README.md` 缺 `docs/i18n.md` 链接；③ `vitest.config.ts` 引用 `./vite.config`（无扩展名）触发 Vite configLoader 警告。

## REV-016 语义修正（执行期裁决，采纳方案 B）
> 取证：`.openfeel/tmp/op-001-stage02-blocked.md`。`pnpm remove shadcn` 后 `pnpm build` EXIT 1（`enhanced-resolve` 无法解析 `shadcn/tailwind.css`）。
> 裁决：**不删除、不改 `src/index.css`、不新增源码**，仅将 `shadcn` 由 `dependencies` 迁至 `devDependencies`（构建期依赖）。**REV-016 新验收标准**：「`shadcn` 不在 `dependencies`（存在或不在 `devDependencies` 均可接受，本方案置于 `devDependencies`），且 `pnpm build` 通过」。该修正需 reviewer 复查确认。
