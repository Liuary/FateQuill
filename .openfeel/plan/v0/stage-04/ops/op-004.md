## 目标
基于官方 `@tiptap/markdown`（3.31.4）提供 Markdown 导入/导出，并以 **≥8 项**语法往返用例（语义等价）验收。

## `@tiptap/markdown` API（已核对 3.31.4 源码/类型）
- 扩展：`import { Markdown } from "@tiptap/markdown"`（已在 `editorExtensions` 中）。
- **导出**：`editor.getMarkdown(): string`（`getJSON()` → markdown）。
- **导入**：`editor.commands.setContent(md, { contentType: "markdown" })`；`ContentType = 'json' | 'html' | 'markdown'`。
- 也可用 `new MarkdownManager({ extensions })` 做纯 `parse(md)` / `serialize(json)`。

## 语法清单（≥8 项，全部覆盖）
h1、h2、h3、粗体 `**`、斜体 `*`、删除线 `~~`、无序列表 `-`、有序列表 `1.`、引用 `>`、行内代码 `` ` ``、代码块 ```` ``` ````、分割线 `---`、链接 `[text](url)`。

## 实施步骤
- [ ] 1. 新增 `src/features/editor/markdown.ts`：文档级 HTML↔Markdown 助手（复用 headless Editor，避免 UI 依赖）
  ```ts
  import { Editor } from "@tiptap/core";
  import { editorExtensions } from "./editor-extensions";

  /** Markdown → HTML（经 Tiptap 解析，用于导入） */
  export function markdownToHtml(markdown: string): string {
    const editor = new Editor({ extensions: editorExtensions, content: "" });
    editor.commands.setContent(markdown, { contentType: "markdown" });
    const html = editor.getHTML();
    editor.destroy();
    return html;
  }

  /** HTML → Markdown（经 Tiptap 序列化，用于导出） */
  export function htmlToMarkdown(html: string): string {
    const editor = new Editor({ extensions: editorExtensions, content: html });
    const md = editor.getMarkdown();
    editor.destroy();
    return md;
  }
  ```
  > 接线：T5 保存沿用 `getHTML()`（`content_format='html'`）；Markdown 仅作**输入/导出**辅助，不改变存储格式（零迁移）。
