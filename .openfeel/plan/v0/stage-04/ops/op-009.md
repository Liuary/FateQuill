# op-009：AI 增量插入接口 EditorController（T8）

- **阶段**：v0.1.0-stage-04
- **状态**：pending
- **前置**：op-003（T2 编辑器）、stage-03（软：`subscribeChunks`/`throttleChunks`）
- **负责 Agent**：openfeel-executor
- **最多重试**：3

## 目标
交付编辑器对外**最小命令面** `EditorController.appendChunk(text, options?)` / `flushPending()`，并实现撤销会话合并与 IME 排队；供 stage-05 `generationStore` 订阅 stage-03 `subscribeChunks` 后消费（stage-05 不直接操作编辑器内部）。

## 定稿约定（plan v2 REV-002）
- 接口签名（预留 options）：
  - `appendChunk(text: string, options?: { addToHistory?: boolean; follow?: boolean }): void` —— 增量追加到文末（节流批次应用）；
  - `flushPending(): void` —— 立即应用队列中待插入内容。
- **撤销栈策略**：一次「生成会话」的插入**合并为单条历史记录**（会话起止标记）；`Ctrl+Z` 一次撤销整段生成。
- **IME 排队**：`composition` 进行中时 Chunk 入队，`compositionend` 后 flush。
- **光标/滚动**：默认不强制滚动（`follow` 可配）。
- 消费方：stage-05 订阅 `subscribeChunks` → 取 `Chunk.delta` → `appendChunk`。

## 机制（prosemirror-history 分组合并，REV-009）
- **流式插入保持默认入历史**（**不使用** `addToHistory:false`）：由 prosemirror-history 的 `newGroupDelay` 时间窗把相邻插入**自动合并为一条历史**。
- **分组窗口 = 5000ms**：在编辑器扩展层配置 `StarterKit.configure({ undoRedo: { newGroupDelay: 5000 } })`（op-002 `editor-extensions.ts`；默认 500ms → 提升到 5000ms）。生成期间 50ms 间隔的连续插入落入同一组 → **一次撤销移除整段生成**；用户手动编辑（超窗/光标移动）自然断组，不与生成混淆。
- **删除旧方案**：不再追踪 `sessionStart` / `commitSession`，**移除** `delete+insert 同文本` 逻辑（该方案 undo 净零、且会误删会话前内容与生成期间的用户输入——两个连带缺陷随之消除）。
- **options.addToHistory 语义调整**：`AppendOptions` 保留 `addToHistory?`（签名兼容），但当前实现**恒入历史**（由 `newGroupDelay` 合并）；字段标注为预留。

## 实施步骤
- [ ] 1. `src/features/editor/EditorController.ts`
  ```ts
  import type { Editor } from "@tiptap/react";

  /**
   * appendChunk options：
   * - follow：插入后是否滚动到文末（默认 false）。
   * - addToHistory：**预留字段**；当前实现恒入历史（由编辑器 `newGroupDelay=5000` 合并为单条，REV-009），暂不生效。
   */
  export interface AppendOptions { addToHistory?: boolean; follow?: boolean }
  export interface EditorController {
    appendChunk(text: string, options?: AppendOptions): void;
    flushPending(): void;
    dispose(): void;   // 卸载时移除 DOM 监听（REV-010）
  }

  /** 构造编辑器增量插入控制器（节流批次 + 撤销分组合并 + DOM 级 IME 排队） */
  export function createEditorController(editor: Editor, opts?: { throttleMs?: number }): EditorController {
    const throttleMs = opts?.throttleMs ?? 50;
    let buffer = "";
    let timer: ReturnType<typeof setTimeout> | null = null;
    let composing = false;
    let follow = false;

    // IME：监听 ProseMirror 视图 DOM —— Tiptap editor 事件总线不含 composition 事件（REV-010）
    const dom = editor.view.dom;
    const onCompositionStart = () => { composing = true; };
    const onCompositionEnd = () => { composing = false; if (buffer) apply(); };
    dom.addEventListener("compositionstart", onCompositionStart);
    dom.addEventListener("compositionend", onCompositionEnd);

    const apply = () => {
      timer = null;
      if (!buffer || composing) return;               // 组合期间排队，compositionend 后 flush
      // 默认入历史（不设 addToHistory:false）；由 newGroupDelay=5000 合并为单条（REV-009）
      const tr = editor.state.tr.insertText(buffer, editor.state.doc.content.size);
      editor.view.dispatch(tr);
      buffer = "";
      if (follow) editor.commands.scrollIntoView();
    };

    return {
      appendChunk(text) { buffer += text; if (timer == null) timer = setTimeout(apply, throttleMs); },
      flushPending() { if (timer) { clearTimeout(timer); timer = null; } apply(); },
      dispose() {
        if (timer) clearTimeout(timer);
        dom.removeEventListener("compositionstart", onCompositionStart);
        dom.removeEventListener("compositionend", onCompositionEnd);
      },
    };
  }
  ```
  > 撤销合并**不依赖控制器**：由 `StarterKit.configure({ undoRedo: { newGroupDelay: 5000 } })`（op-002）在 prosemirror-history 层完成——流式插入恒入历史并按时间窗合并，`Ctrl+Z` 一次撤销整段生成；用户编辑自然断组。
- [ ] 2. `src/features/editor/useChunkInjection.ts`：桥接 stage-03 消费工具
  ```ts
  import type { Editor } from "@tiptap/react";
  import type { Chunk } from "@/orchestration/types";
  import { subscribeChunks } from "@/orchestration/stream";
  import { createEditorController } from "./EditorController";

  /** 订阅 Chunk 异步流 → 经节流 → 增量插入编辑器；返回取消函数 */
  export function injectChunkStream(editor: Editor, source: AsyncIterable<Chunk>): () => void {
    const controller = createEditorController(editor);
    let cancelled = false;
    (async () => {
      for await (const chunk of subscribeChunks(source)) {   // 复用 stage-03 节流（≥50ms 合并）
        if (cancelled) return;
        controller.appendChunk(chunk.delta);
      }
      controller.flushPending();
    })();
    return () => { cancelled = true; };
  }
  ```
- [ ] 3. 测试 `EditorController.test.ts`（jsdom + headless Editor + 假 Chunk 流）
  - **编辑器配置**：使用 `editorExtensions`（含 `undoRedo: { newGroupDelay: 5000 }`）；**记录生成前文档 HTML/文本**；
  - **增量追加到文末**：`appendChunk("你好")` + `flushPending()` → 文档末尾含「你好」；多 chunk 拼接正确；
  - **节流合并**：spy `editor.view.dispatch` 调用次数 ≤ chunk 数（50ms 窗口合并）；
  - **撤销整段（REV-009 新机制）**：快速连续插入 N 个 chunk（同一时间窗内）→ `flushPending()` → 调一次 `editor.commands.undo()` → 文档恢复为**生成前** HTML（整段一次性移除）；再断言**不会**撤销会话前内容（生成前文档在 undo 前存在、undo 后回到生成前状态）；
  - **IME 排队（REV-010）**：`editor.view.dom.dispatchEvent(new CompositionEvent("compositionstart"))` → `appendChunk`/`apply` 不立即入档；`dispatchEvent(new CompositionEvent("compositionend"))` 后内容出现；
  - **dispose**：`dispose()` 后 DOM 上无残留 composition 监听（再次派发 composition 事件不再改变行为）。
  > 用 headless `new Editor({ extensions: editorExtensions })`；假流用 `async function* { yield {delta:"..."} }`；时间窗合并依赖 `newGroupDelay=5000`，同一 tick 内的多次插入必然同组。
