- **指标**：按键事件 → Tiptap `dispatchTransaction` → 编辑器 DOM 更新完成的耗时；在 `editor.on('transaction')` 前后 `performance.now()` 埋点（或 `requestAnimationFrame` 对齐帧），统计 **P95**。
- **载荷**：前端 seed 生成 **5000 字 HTML** 文档。
- **环境**：**真实 WebView**（`tauri dev` 窗口内 BenchPanel 输出）；**jsdom 无布局，明确不可用于延迟测量**。
- **内存**：连续切换 **20 章**（含 5000 字章）后，`document.querySelectorAll('.ProseMirror').length === 1`（实例恒为 1）；堆增幅 **< 20%**（`performance.memory.usedJSHeapSize`）。
- **IME 口径**：中文 `composition` 期间延迟**单独统计或排除**，报告注明。

## 实施步骤
- [ ] 1. `src/features/editor/perf/seed.ts`：5000 字 HTML 生成器
  ```ts
  /** 生成约 chars 个非空白字符的 HTML（段落切分），用于性能载荷 */
  export function makeHtml(chars: number, paragraphs = 20): string {
    const per = Math.ceil(chars / paragraphs);
    const body = Array.from({ length: paragraphs }, () => `<p>${"字".repeat(per)}</p>`).join("");
    return body;
  }
  ```
- [ ] 2. `src/features/editor/perf/editor-bench.ts`：埋点 + P95
  ```ts
  import type { Editor } from "@tiptap/react";

  /** 计算 P95（升序样本） */
  export function p95(samples: number[]): number {
    if (samples.length === 0) return 0;
    const s = [...samples].sort((a, b) => a - b);
    return s[Math.min(s.length - 1, Math.ceil(0.95 * s.length) - 1)];
  }

  /** 在真实 WebView 中运行：逐次插入文本并测量「dispatch→DOM」耗时，返回 P95(ms) */
  export async function runEditorBench(editor: Editor, insertions = 200): Promise<number> {
    const samples: number[] = [];
    for (let i = 0; i < insertions; i++) {
      const t0 = performance.now();
      editor.commands.insertContent("字");
      await new Promise<void>((r) => requestAnimationFrame(() => r())); // 对齐帧预算
      samples.push(performance.now() - t0);
    }
    return p95(samples);
  }
  ```
