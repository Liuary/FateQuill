# op-006：自动保存与状态提示：防抖/flush/重试（T5）

- **阶段**：v0.1.0-stage-04
- **状态**：pending
- **前置**：op-003（T2 章节切换与 editorStore）
- **负责 Agent**：openfeel-executor
- **最多重试**：3

## 目标
实现可靠的自动保存：**防抖 800ms** + **flush 三时机**（切章前 await / 窗口关闭前 / 失焦可选）+ **失败置脏 + 5s 重试**，并有两条可判定单测。

## 定稿约定（plan v2）
- 防抖时长 **800ms**。
- **flush 时机**：① **切章前同步 flush**（`await` 保存完成再销毁实例）；② 窗口关闭（Tauri `onCloseRequested` / `beforeunload`）前 flush；③ 可选：编辑器失焦 flush。
- 失败策略：保存失败（如 `DB_LOCKED`/`INTERNAL`/`TIMEOUT`）→ `editorStore.saveStatus='dirty'` + UI 未保存指示；**定时重试 5s（带退避/上限）**，不得静默丢弃。
- `word_count` 不由前端计算（Rust 保存时回填，stage-02 纪律）。
- 保存载荷：`update_chapter(id, { title, content: editor.getHTML(), contentFormat:'html', status, orderIndex })`。

## 实施步骤
- [ ] 1. 新增 `src/features/editor/useAutoSave.ts`
  ```ts
  import { useCallback, useEffect, useRef } from "react";
  import type { Editor } from "@tiptap/react";
  import type { Chapter } from "@/domain/models/chapter";
  import { IpcError } from "@/ipc/errors";
  import { repositories } from "@/ipc/repositories";
  import { useEditorStore } from "@/store/editorStore";

  const DEBOUNCE_MS = 800;
  const RETRY_MS = 5000;
  const MAX_RETRY = 5;

  export interface AutoSaveMeta { title: string; status: Chapter["status"]; orderIndex: number; }

  /** 自动保存：防抖 800ms；失败置脏并 5s 重试（退避/上限）；保存串行化（REV-011）；暴露 flush() */
  export function useAutoSave(editor: Editor | null, chapterId: number | null, meta: AutoSaveMeta) {
    const { setSaveStatus, markSaved } = useEditorStore.getState();
    const timer = useRef<ReturnType<typeof setTimeout> | null>(null);
    const retry = useRef(0);
    const dirtyRef = useRef(false);
    const chainRef = useRef<Promise<void>>(Promise.resolve()); // 保存串行化链（REV-011）

    /**
     * 串行化保存（REV-011）：所有保存串到同一条 promise 链 → 后写必然在完成前写之后执行，
     * 且执行时**重新取 `editor.getHTML()`**（最新内容优先），消除「慢写旧内容覆盖新写」。
     */
    const enqueueSave = useCallback((): Promise<void> => {
      chainRef.current = chainRef.current.then(async () => {
        if (editor == null || chapterId == null || !dirtyRef.current) return;
        setSaveStatus("saving");
        try {
          await repositories.chapter.update(chapterId, {
            title: meta.title, content: editor.getHTML(), contentFormat: "html",
            status: meta.status, orderIndex: meta.orderIndex,
          });
          dirtyRef.current = false; retry.current = 0; markSaved();
        } catch {
          setSaveStatus("dirty"); // 失败保留脏态，不静默丢弃
          if (retry.current < MAX_RETRY) {
            const delay = RETRY_MS * (retry.current + 1); // 线性退避
            retry.current += 1;
            setTimeout(() => { void enqueueSave(); }, delay);
          } else { setSaveStatus("error"); }
        }
      });
      return chainRef.current;
    }, [editor, chapterId, meta.title, meta.status, meta.orderIndex, setSaveStatus, markSaved]);

    /** 立即保存（取消防抖并等待链尾完成） */
    const flush = useCallback(async () => {
      if (timer.current) { clearTimeout(timer.current); timer.current = null; }
      await enqueueSave();
    }, [enqueueSave]);

    /** 文档变更：置脏 + 重置防抖计时 */
    const schedule = useCallback(() => {
      dirtyRef.current = true; setSaveStatus("dirty");
      if (timer.current) clearTimeout(timer.current);
      timer.current = setTimeout(() => { void enqueueSave(); }, DEBOUNCE_MS);
    }, [enqueueSave, setSaveStatus]);

    useEffect(() => {
      if (!editor) return;
      editor.on("update", schedule);
      return () => { editor.off("update", schedule); };
    }, [editor, schedule]);

    useEffect(() => () => { if (timer.current) clearTimeout(timer.current); }, []);
    return { flush, saveNow: enqueueSave };
  }
  ```
