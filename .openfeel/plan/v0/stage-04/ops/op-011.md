# op-011：修复 DEV 模式 UI 遮挡与空态布局（BenchPanel 折叠 / NewNovelPanel 高度）(fix)

- **阶段**：v0.4.0-stage-04（回归修复；用户报告）
- **状态**：done
- **前置**：stage-04 编辑器与 perf 基准面板（已归档）
- **负责 Agent**：openfeel-executor
- **最多重试**：3
- **关联缺陷**：用户报告（DEV 模式）——`pnpm tauri dev` 下 **`BenchPanel` 无条件挂载**，其 5000 字种子编辑器铺满整屏并把工作区界面盖住；空态 `NewNovelPanel` 卡片定位错乱（`min-h-screen` 在 flex 内容区溢出）。

## 变更目标

1. **`BenchPanel` 折叠式、默认收起**：默认仅一行小按钮「性能基准 (DEV)」；点击展开 / 收起；**展开时编辑器区加高度约束**（`max-h-48 overflow-auto`）→ 不再铺满、不再遮盖工作区。
2. **`NewNovelPanel` 高度修正**：`min-h-screen` → `min-h-full`（适配父容器 flex 内容区），空态卡片**垂直水平居中且不溢出**。
3. **不改变** `BenchPanel` 的三个基准功能与断言（延迟 / 实例数 / 堆增幅）；**不新增依赖**。

## 涉及文件

- 新建：`.openfeel/plan/v0/stage-04/ops/op-011.md`（本文件）
- 修改：`src/features/editor/perf/BenchPanel.tsx`（折叠开关 + 展开态高度约束）
- 修改：`src/features/editor/NewNovelPanel.tsx`（`min-h-screen` → `min-h-full`）
- （`src/app/App.tsx` 的 `{import.meta.env.DEV && <BenchPanel />}` 保留：改为折叠后不再遮挡，无需改 App 结构）
