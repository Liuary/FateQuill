# v0.3.0-stage-08 详细计划：多温度并行推演引擎

## 归属版本
v0.3（创造引导）

## 目标
以多 agent、不同温度并行推演剧情走向，呈现可对比分支，并在用户设定约束下克制收敛。

## 对应核心目的
- 目的 1：把「接下来怎么发展」从单点生成升级为可选分支，辅助创作者决策。
- 目的 2：多温度产出扩大对照样本，利于观察 AI 味与真人感差异。

## 前置依赖
v0.1.0-stage-03（引擎）、v0.1.0-stage-05（生成闭环）；软依赖 v0.2.0-stage-06（质量筛选）

## 技术约束（本阶段适用）
- 并行执行：多 agent 同任务不同温度，统一结果汇总（复用 stage-03 Pipeline）。
- **克制收敛**：推演结果须向用户设定（设定卡/大纲/约束）收敛，不得脱离设定自由发散。
- 结果可对比、可采纳、可丢弃；采纳写入作品（显式动作）。
- 并发与成本控制：并行度可配置，有失败降级。

## 任务表

| # | 任务 | 交付物 | 验收标准 | 依赖 |
|---|------|--------|----------|------|
| T1 | 多温度并行推演编排 | 推演 Pipeline（温度参数化） | N 个温度并行产出 N 份推演（测试） | stage-03 |
| T2 | 推演结果分支视图 | 分支对比 UI | 并排展示、可折叠、可标注差异 | T1 |
| T3 | 收敛机制 | 约束注入 + 收敛器 | 偏离设定的推演被削弱/标注（可测） | T1,stage-05 |
| T4 | 采纳/丢弃与落库 | 采纳动作 + 存储 | 采纳后写入作品；丢弃不留残留 | T2 |
| T5 | 并发与失败处理 | 并发控制 + 降级 | 单分支失败不影响其余；有重试/跳过 | T1 |

## 阶段验收标准（DoD）
- [ ] 可配置并行度，多温度分支正确产出。
- [ ] 分支可对比、采纳、丢弃，且持久化正确。
- [ ] 收敛机制可验证：偏离用户设定的分支被抑制或显式提示。
- [ ] 单分支失败可降级，不阻塞整体。

## 风险与备注
- 「克制收敛」的度量需先定义（如与设定卡关键词/约束的贴合度），否则不可判定。
- 并行 API 成本随分支数增长，UI 需提示预估消耗。
