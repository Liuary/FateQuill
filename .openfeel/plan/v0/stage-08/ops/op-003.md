# op-003：克制收敛（两层）：约束注入与偏离标注收敛器（T3）

- **阶段**：v0.3.0-stage-08

- **负责 Agent**：openfeel-executor
- **最多重试**：3

## 目标
实现**两层克制收敛**：① **生成期约束注入**——设定卡/关键约束经装配链进 **system 段**（`intent` 为 user 段）；② **产出期偏离标注收敛器**——以 **`settingCardIds` 覆盖检查**为判据（含**存在性校验：过滤无效 id**）+ 可选贴合度 → **排序降权 + UI 显式标注（不过滤、不删除）**；终选权归用户。

## 定稿约定（plan v2 REV-001 + 审查非阻塞提示）
- ① 注入：**约束进 system 段**（`build-exploration-options` 把设定卡文本并入 system prompt）；`intent` 为 user 段。
- ② 判据：`coverage = |card.settingCardIds ∩ 注入集| / |注入集|`；**存在性校验**——`card.settingCardIds` 中**不存在于该作品设定卡集**的 id 视为**幻觉引用**（过滤 + 记录 + 计为偏离）。
- ③「削弱」= **排序降权 + UI 标注**（不删不改，保持可对比）；④「克制」= 温度集控制发散；⑤ **终选权 = 用户裁决**（自动收敛仅辅助排序）。
- 可选④：复用 stage-06 评审管线加「贴合度」评估（**软依赖**，缺省不启用）。

- [ ] 2. `converge.ts`（纯函数）
  ```ts
  export interface ConvergeOptions {
    injectedSettingCardIds: number[];
    existingSettingCardIds: Set<number>;   // 存在性校验基准
    coverageThreshold?: number;            // 默认 0.5
    fitScores?: Record<string, number>;    // 可选：贴合度（stage-06 复用）
  }
  /** 收敛：覆盖检查 + 存在性校验（过滤无效 id）+ 降权；返回更新后的分支与按权重降序的顺序（不过滤不删） */
  export function converge(branches: ExplorationBranch[], opts: ConvergeOptions): ExplorationBranch[] { /* ... */ }
  ```
  - 存在性校验：`card.settingCardIds = card.settingCardIds.filter(id => existingSettingCardIds.has(id))`；被过滤的真实幻觉 id 记入 `deviation.invalidSettingCardIds`。
  - `coverage`；`flagged = coverage < threshold || invalidSettingCardIds.length > 0 || (fitScore < threshold)`；`weight = flagged ? coverage * 0.5 : coverage`。
    > **边界注释（REV-008③）**：`flagged && coverage=1.0 → weight 0.5` 与 `未 flagged && coverage=0.5 → weight 0.5` 可能并列；v0.3 **接受**（偏离通常另有 `invalid`/`fitScore` 触发；并列时按温度序稳定排序）——代码中**注释注明**，不额外引入权重维度。
  - 分支写入 `deviation`/`weight`；**排序由 weight 降序**（调用方/视图用），**不移除任何分支**。
- [ ] 3. `explorationStore.ts`：`ExplorationBranch` 增 `deviation`/`weight`（类型见 op-001）+ `updateBranch` 已有；收敛后 `setBranches(converged)`。
