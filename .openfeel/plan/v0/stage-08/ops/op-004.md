> **修订（REV-007）**：采纳原「整章替换当前章 + 版本池登记仅可选」叠加 `useAutoSave` 自动保存，存在**误触导致原正文 DB 级永久丢失**隐患。本 op 引入**无损落地主路径 + 危险次路径安全网**（见「采纳目标决策」）。

## 目标
交付分支落地：**主路径「新建下一章草稿」**（不改当前章 → **无 DB 丢失风险**，贴合推演语义）+ **危险次路径「替换当前章」**（确认 + **强制入池快照**）；两者均带**确认对话框**；丢弃 = 会话快照清空（无残留）。

## 采纳目标决策（REV-007 ③，由 schemer 定稿）
- **主路径 = 新建下一章草稿**（`repositories.chapter.create`，内容 = 走向卡 HTML，追加到当前章所属卷末）：
  **理由**：① 推演语义是「接下来怎么发展」，落地为**下一章**最贴合；② **不改动当前章 DB 行** → 在**无新增迁移**（方案 A）前提下**根除 DB 级丢失**（自动保存不会覆盖原正文）；③ 与「终选权=用户」一致（用户明确选择要一个新章草稿）。
- **次路径 = 替换当前章（危险）**：保留 plan 原 `EditorController.replaceContent`（单条撤销）契约，但升级为**确认对话框 + 替换前强制入池快照**（把原「可选登记」改为**必做**），使会话内始终可恢复原正文。
- **对 plan DoD 2 的对齐声明**：DoD 2「采纳后正文变更且单次 `Ctrl+Z` 恢复」原基于「替换」；现**主路径（新建章）不编辑当前章 → `Ctrl+Z` 语义不适用**，`Ctrl+Z` 语义归于**次路径替换**。**请 planner/Feel 对齐 DoD 2 措辞**（本 op 不擅自改 plan）。

## 定稿约定（plan v2 REV-003 —— 方案 A；本 op 修订）

- **无残留定义**：丢弃后该分支不出现在 `explorationStore` 快照、无悬挂引用。

  ```ts
  import type { Editor } from "@tiptap/react";
  import { repositories } from "@/ipc/repositories";
  import { createEditorController } from "@/features/editor/EditorController";
  import { useReviewStore } from "@/store/reviewStore";
  import { useExplorationStore } from "@/store/explorationStore";
  import { renderTurnCardToHtml } from "./render-turn-card";

  export function useAdoptBranch(editor: Editor | null) {
    /** 主路径：新建下一章草稿（**不改当前章** → 无 DB 丢失） */
    const adoptAsNextChapter = async (branchId: string, currentChapterId: number): Promise<boolean> => {
      const branch = useExplorationStore.getState().branches.find((b) => b.id === branchId);
      if (!branch?.card) return false;
      const current = await repositories.chapter.get(currentChapterId);            // 取 volumeId/orderIndex
      const siblings = await repositories.chapter.listByVolume(current.volumeId);
      const orderIndex = siblings.reduce((m, c) => Math.max(m, c.orderIndex), -1) + 1;
      await repositories.chapter.create({                                          // 新建章（当前章不动）
        volumeId: current.volumeId, title: /* i18n nextChapterTitle */, 
        content: renderTurnCardToHtml(branch.card), contentFormat: "html", orderIndex,
      });
      useExplorationStore.getState().selectBranch(branchId);
      return true;
    };

    /** 次路径（危险）：替换当前章——**先强制入池快照（必做）**，再 replaceContent（单撤销） */
    const replaceCurrentChapter = (branchId: string, currentContentHtml: string): boolean => {
      const branch = useExplorationStore.getState().branches.find((b) => b.id === branchId);
      if (!editor || !branch?.card) return false;
      // ② 强制安全网（必做，非可选）：把**替换前正文**入 stage-06 版本池（会话内始终可恢复）
      useReviewStore.getState().addVersion({ id: crypto.randomUUID(), label: "adopt-safety", content: currentContentHtml, round: -1, results: {} });
      const controller = createEditorController(editor);
      try { controller.replaceContent(renderTurnCardToHtml(branch.card)); }   // 单条撤销
      finally { controller.dispose(); }
      useExplorationStore.getState().selectBranch(branchId);
      return true;
    };

    const discard = (branchId: string) => { useExplorationStore.getState().removeBranch(branchId); };
    return { adoptAsNextChapter, replaceCurrentChapter, discard };
  }
  ```
