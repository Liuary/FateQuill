### 定稿要点（摘要）
- **推演契约**：温度集默认 `{0.3,0.7,1.1}`（可调/持久化）；per-provider clamp + 标注；**同模型多温度**；输出结构化「走向卡」；落点 `src/orchestration/exploration/` + `src/features/exploration/`。
- **克制收敛（两层）**：生成期约束注入（复用 `ChapterPromptInput`）+ 产出期偏离标注（覆盖检查 + 可选贴合度）→ **降权 + 标注**，不删不改，**终选权归用户**。
- **持久化（方案 A）**：分支=会话内存（`explorationStore`），**不新增迁移**；**采纳双路径**——主「新建下一章草稿」（`chapter.create`，不改当前章，不适用 `Ctrl+Z`）/ 次「替换当前章」（`EditorController.replaceContent` + 确认 + 强制入池快照 + **单条撤销**，`Ctrl+Z` 归此）；丢弃无残留。
- **并行工程**：并行度上限 3 + 排队 + 成本预估 + 部分结果 + 单独重试 + abort 全停。
- **i18n** `exploration`；**无新增 Rust 命令**（复用 `http_stream`，非流式收口）。
