## 目标
接入 TailwindCSS v4（CSS-first，无 `tailwind.config.js`）与 shadcn/ui（组件源码入库），落地 ≥3 个组件于 `src/components/ui/`，并建立 shadcn 所需的 `@/*` 别名与 `cn` 工具。单一交付物：可渲染、可构建的 Tailwind v4 + shadcn/ui 组件基础设施。

## 前置说明与决策
- shadcn CLI 运行前提：`@/*` 路径别名已配置、`src/index.css` 已接入 Tailwind。本 op 内完成**最小别名配置**（供 shadcn 使用）；op-003 负责目录分层与别名的**权威同步与文档化**。
- **约定路径（决策）**：shadcn 组件固定落于 `src/components/ui/`（满足阶段计划 T2 与 REV-007③）。`plan.md` T3 中的 `ui` 层映射为 `src/components/`（shadcn 约定路径），op-003 会在 `docs/structure.md` 记录该映射，并另建 `src/ui/` 作为通用 UI 层目录。

## 涉及文件/目录
- 新增：`src/index.css`、`components.json`、`src/lib/utils.ts`、`src/components/ui/{button,card,input}.tsx`
- 修改：`vite.config.ts`、`tsconfig.json`、`package.json`、`src/main.tsx`、`src/App.tsx`

## 实施步骤
- [ ] 1. 安装 Tailwind v4 与类型依赖
  ```powershell
  corepack pnpm add -D tailwindcss@4.3.3 @tailwindcss/vite@4.3.3 @types/node@26.6.4
  ```
- [ ] 2. 修改 `vite.config.ts`：注册 Tailwind 插件 + `@` 别名，并移除原 `@ts-expect-error`（`@types/node` 已装）
  ```ts
  import { defineConfig } from "vite";
  import react from "@vitejs/plugin-react";
  import tailwindcss from "@tailwindcss/vite";
  import { fileURLToPath, URL } from "node:url";

  export default defineConfig(() => {
    const host = process.env.TAURI_DEV_HOST;
    return {
      plugins: [react(), tailwindcss()],
      resolve: { alias: { "@": fileURLToPath(new URL("./src", import.meta.url)) } },
      clearScreen: false,
      server: {
        port: 1420,
        strictPort: true,
        host: host || false,
        hmr: host ? { protocol: "ws", host, port: 1421 } : undefined,
        watch: { ignored: ["**/src-tauri/**"] },
      },
    };
  });
  ```
  > **ESM 注意**：`package.json` 为 `"type": "module"`，不可用 `__dirname`；改用 `import.meta.url` + `fileURLToPath`（Vite 官方 ESM 写法）。
- [ ] 3. `tsconfig.json` 的 `compilerOptions` 增加别名
  ```json
  "baseUrl": ".",
  "paths": { "@/*": ["./src/*"] }
  ```
- [ ] 4. 新建 `src/index.css`（Tailwind v4 入口，CSS-first）
  ```css
  @import "tailwindcss";
  ```
- [ ] 5. `src/main.tsx` 顶部引入样式：`import "./index.css";`（置于 `./App` 之前）。
- [ ] 6. 初始化 shadcn/ui（Tailwind v4 + Vite 项目内）
  - **前置校验（REV-013）**：先运行 `corepack pnpm dlx shadcn@latest init --help`，确认 `-b` 的语义。
    - 若 `-b` = **base library**（值为 base / radix / aria）：使用下方命令。
    - 若 `-b` = **base-color**（值为 neutral/gray/zinc/stone/slate）：改用 `-b neutral`（与附录 A 的 `"baseColor": "neutral"` 一致），并在附录 A 补对应字段。
  ```powershell
  corepack pnpm dlx shadcn@latest init -b radix --css-variables --no-monorepo --yes
  ```
  预期：生成 `components.json` 与 `src/lib/utils.ts`，并向 `src/index.css` 注入 shadcn 主题变量（含 `@theme inline`）。
  > **回退（若 init 交互失败或未识别框架）**：手动创建 `components.json`（见附录 A）、`src/lib/utils.ts`（见附录 B），并执行：
  > `corepack pnpm add clsx@2.1.1 tailwind-merge@3.7.0 class-variance-authority@0.7.1 lucide-react@1.53.0` 与 `corepack pnpm add -D tw-animate-css@1.4.0`；`src/index.css` 需含附录 C 的主题变量。
- [ ] 7. 补充 shadcn 依赖（若 init 未自动安装）
  ```powershell
  corepack pnpm add clsx@2.1.1 tailwind-merge@3.7.0 class-variance-authority@0.7.1 lucide-react@1.53.0
  corepack pnpm add -D tw-animate-css@1.4.0
  ```
- [ ] 8. 添加 3 个组件（源码入库）
  ```powershell
  corepack pnpm dlx shadcn@latest add button card input --yes
  ```
  确认 `src/components/ui/button.tsx`、`card.tsx`、`input.tsx` 存在且可编辑。
- [ ] 9. 临时渲染校验：改写 `src/App.tsx` 为一个最小页面，使用 `<Button>` 与 Tailwind 类（旧 logo/greet 逻辑移除，后续 op 继续迭代）
  ```tsx

    return (

- [ ] 10. 构建校验

  ```

## 附录 B：`src/lib/utils.ts`（回退用）
```ts
import { clsx, type ClassValue } from "clsx";
import { twMerge } from "tailwind-merge";

/** 合并 Tailwind 类名，处理冲突 */
export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
```

## 附录 C：`src/index.css` 主题变量骨架（回退用）
> Tailwind v4 的 shadcn 主题为 CSS 变量 + `@theme inline`。优先由 `shadcn init` 自动生成；回退时至少包含 `@import "tailwindcss";`、`:root` / `.dark` 变量块与 `@theme inline` 映射。若手写不完整，可再运行 `shadcn init` 覆盖。
