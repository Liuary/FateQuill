# op-005：实现 Rust IPC ping 命令与命令通道约定文档 docs/ipc.md（T5）

- **阶段**：v0.1.0-stage-01
- **状态**：pending
- **前置**：op-001、op-003
- **负责 Agent**：openfeel-executor
- **最多重试**：3

## 目标
实现并跑通一条 Rust → 前端 的 IPC 命令通道：Rust `#[tauri::command] ping` + 前端 `invoke`，并输出命令通道注册约定文档 `docs/ipc.md`（事件流通道留待 stage-03）。

## 前置说明
- 替换脚手架示例 `greet` 为 `ping`，移除未使用的 `tauri-plugin-opener`（脚手架演示依赖），避免死依赖。
- 前端 IPC 统一封装于 `src/ipc/`，组件不直接 `invoke`（符合计划分层与 C-04 边界约定）。

## 涉及文件/目录
- 修改：`src-tauri/src/lib.rs`、`src-tauri/Cargo.toml`、`src-tauri/capabilities/default.json`、`package.json`、`src/app/App.tsx`
- 新增：`src/ipc/ping.ts`、`docs/ipc.md`
- 清理：移除 `@tauri-apps/plugin-opener` 依赖与 `tauri-plugin-opener`

## 实施步骤
- [ ] 1. 改写 `src-tauri/src/lib.rs`：以 `ping` 替换 `greet`，并移除 opener 插件
  ```rust
  // 命令通道示例：前端 invoke("ping") 返回 "pong"
  #[tauri::command]
  fn ping() -> String {
      "pong".to_string()
  }

  #[cfg_attr(mobile, tauri::mobile_entry_point)]
  pub fn run() {
      tauri::Builder::default()
          .invoke_handler(tauri::generate_handler![ping])
          .run(tauri::generate_context!())
          .expect("error while running tauri application");
  }

  #[cfg(test)]
  mod tests {
      use super::*;

      #[test]
      fn ping_returns_pong() {
          assert_eq!(ping(), "pong");
      }
  }
  ```
- [ ] 2. 移除未使用的 opener 插件
  - `src-tauri/Cargo.toml`：删除 `tauri-plugin-opener = "2"`。
  - `src-tauri/capabilities/default.json`：`permissions` 由 `["core:default", "opener:default"]` 改为 `["core:default"]`。
  - `package.json`：从 dependencies 移除 `@tauri-apps/plugin-opener`。
  > 删除后需重跑 `corepack pnpm install` 以更新锁文件。
- [ ] 3. 新增前端 IPC 封装 `src/ipc/ping.ts`
  ```ts
  import { invoke } from "@tauri-apps/api/core";

  /** 调用 Rust 侧 ping 命令，返回 "pong" */
  export async function ping(): Promise<string> {
    return invoke<string>("ping");
  }
  ```
- [ ] 4. 改写 `src/app/App.tsx` 为 ping 演示页
  ```tsx
  import { useState } from "react";
  import { Button } from "@/components/ui/button";
  import { ping } from "@/ipc/ping";

  function App() {
    const [result, setResult] = useState("");

    async function handlePing() {
      setResult(await ping());
    }

    return (
      <main className="flex min-h-screen flex-col items-center justify-center gap-4">
        <Button onClick={handlePing}>Ping</Button>
        <p>{result}</p>
      </main>
    );
  }
  export default App;
  ```
- [ ] 5. 新建 `docs/ipc.md`，至少包含：
  - **命令通道注册约定**：Rust 侧用 `#[tauri::command]` 定义，统一在 `tauri::Builder::default().invoke_handler(tauri::generate_handler![...])` 注册；前端统一经 `src/ipc/*.ts` 封装 `invoke`，组件不直接调用。
  - **命名约定**：命令名小写下划线（如 `ping`、后续 `list_novels`）；前端封装函数 camelCase；返回 `Result<T, E>`，错误经 `invoke` 的 `catch` 处理。
  - **参数命名**：Rust 参数 snake_case 与前端 `invoke(cmd, { camelCase })` 的映射规则（Tauri 自动转换）。
  - **边界约定**：外部 HTTP / 密钥 / SQLite 仅在 Rust 侧；前端只经 IPC（对应大计划 C-04）。
  - **事件流通道延后声明**：SSE 流式中继（`emit` / `Channel`）归属 **stage-03**，本阶段不实现。
  - **示例**：`ping` 的完整链路（Rust → `src/ipc/ping.ts` → `App.tsx`）。
