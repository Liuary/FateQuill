# op-003：确立目录分层与路径别名 @/* 及目录约定文档（T3）

- **阶段**：v0.1.0-stage-01
- **状态**：pending
- **前置**：op-001、op-002
- **负责 Agent**：openfeel-executor
- **最多重试**：3

## 目标
确立与 plan v3 一致的分层目录 `src/{app,components,features,domain,orchestration,ipc,store}`（其中 `ui` 层映射为 `src/components/`，shadcn 源码落 `src/components/ui/`）、`src-tauri/` Rust 侧边界与 `@/*` 别名，并将目录职责、`store/` 初始化时机、Zustand 归属写入 `docs/structure.md`；另设通用可复用 UI 组合层 `src/ui/`（布局/非 shadcn 组合组件，显式命名以区别于 plan v3 的 `ui` 层语义）。

## 前置说明与决策
- op-002 已建立最小 `@/*` 别名（tsconfig + vite）供 shadcn 使用；本 op 负责**权威同步（tsconfig 与 vite 双端一致）与文档化**，并创建全部分层目录。
- **目录映射决策（plan v3 定稿）**：plan v3 T3 的目录集为 `src/{app,components,features,domain,orchestration,ipc,store}`，`ui` 层映射为 `src/components/`（shadcn 组件落 `src/components/ui/`）。另设**通用可复用 UI 组合层 `src/ui/`**（布局、非 shadcn 组合组件，如 op-008 的语言切换器），显式命名以区别于 plan v3 的 `ui` 层语义。该映射与理由记入 `docs/structure.md`。
- **Zustand 归属（定稿）**：本阶段**不安装 Zustand**，仅建 `src/store/` 目录。首个接入阶段 = **stage-04**（`editorStore`）；stage-05 增 `generationStore`。此声明必须写入约定文档。

## 涉及文件/目录
- 新建目录（含 `.gitkeep`）：`src/app`、`src/features`、`src/domain`、`src/orchestration`、`src/ipc`、`src/store`、通用层 `src/ui`
- （op-002 已建，`ui` 层与 shadcn）`src/components`、`src/components/ui`、`src/lib`
- 迁移：`src/App.tsx` → `src/app/App.tsx`；`src/main.tsx` → `src/app/main.tsx`；`src/App.css` → `src/app/App.css`（或删除）
- 修改：`index.html`、`tsconfig.json`、`vite.config.ts`（核对）、`src/app/main.tsx`
- 新建：`docs/structure.md`

## 实施步骤
- [ ] 1. 创建分层目录并放置 `.gitkeep`（保证空目录入 Git）
  ```powershell
  $dirs = @("src/app","src/ui","src/features","src/domain","src/orchestration","src/ipc","src/store","src/components","src/components/ui","src/lib")
  foreach ($d in $dirs) {
    New-Item -ItemType Directory -Force -Path $d | Out-Null
    $keep = Join-Path $d ".gitkeep"
    if (-not (Test-Path $keep)) { New-Item -ItemType File -Path $keep | Out-Null }
  }
  ```
- [ ] 2. 迁移前端入口到 `src/app/`
  ```powershell
  git mv src/App.tsx src/app/App.tsx
  git mv src/main.tsx src/app/main.tsx
  git mv src/App.css src/app/App.css
  ```
  > 若 `src/App.css` 已被 Tailwind 取代（无引用），可改为 `git rm src/App.css`。
- [ ] 3. 更新 `index.html` 入口脚本路径
  ```html
  <script type="module" src="/src/app/main.tsx"></script>
  ```
- [ ] 4. 修正迁移后的相对导入
  - `src/app/main.tsx`：`import App from "./App";` 保持；样式改为 `import "../index.css";`（若同时保留 `App.css` 则由 App.tsx 引入）。
  - `src/app/App.tsx`：资源引用改为 `@/assets/...` 或 `../assets/...`；组件引用统一用 `@/components/...`。
- [ ] 5. 核对别名双端一致（**仅核对，不改写**；统一为 ESM 写法，REV-010）
  - `tsconfig.json`：`"baseUrl": "."`、`"paths": { "@/*": ["./src/*"] }`、`"include": ["src"]`。
  - `vite.config.ts`：`resolve.alias["@"] = fileURLToPath(new URL("./src", import.meta.url))`（与 op-002 步骤 2 完全一致）。
  > **禁止**使用 `path.resolve(__dirname, "./src")`：项目 `package.json` 为 `"type": "module"`，ESM 下 `__dirname` 未定义，会导致 `ReferenceError` 与 `pnpm build` 失败。
- [ ] 6. 新建 `docs/structure.md`，至少包含：
  - 分层目录职责表：
    | 目录 | 职责 |
    |------|------|
    | `src/app/` | 应用入口与全局装配（`main.tsx`、`App.tsx`、i18n 初始化、Provider） |
    | `src/components/` | 应用级组合组件（自建） |
    | `src/components/ui/` | shadcn/ui 源码组件（由 shadcn CLI 管理，可改） |
    | `src/ui/` | 通用可复用 UI 层（布局、非 shadcn 组合组件） |
    | `src/features/` | 面向用户的功能模块 |
    | `src/domain/` | 纯 TS 领域模型与业务规则（无 UI、无网络） |
    | `src/orchestration/` | Agent 编排引擎（可插拔） |
    | `src/ipc/` | 前端 IPC 封装（`invoke` 包装） |
    | `src/store/` | 状态管理目录（Zustand 于 stage-04 接入） |
    | `src/lib/` | 通用工具（如 `cn`） |
    | `src/locales/` | i18n 资源（zh-CN / en） |
    | `src-tauri/` | Rust 后端（网络/密钥/SQLite 边界） |
  - 别名约定：`@/*` → `src/*`。
  - `store/` 初始化时机与 **Zustand 归属声明**（见「前置说明与决策」）。
  - IPC 边界：所有外部 HTTP、密钥、SQLite 仅经 Rust 侧，前端只经 `@/ipc` 调用。
- [ ] 7. 构建校验
  ```powershell
  corepack pnpm build
  ```
- [ ] 8. 验证目录与别名
  ```powershell
  Get-ChildItem src -Directory | Select-Object Name
  rg -n "@/lib/utils|@/components/ui" src
  ```
- [ ] 9. **提交本 op 变更（REV-009）**
  ```powershell
  git add -A
  git commit -m "refactor(structure): establish src layers, @/* alias and structure doc (T3)"
  ```
