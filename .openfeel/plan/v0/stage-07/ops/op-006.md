## 目标
落地**规避 skill 库雏形**：`skill_entry` Rust CRUD + 归纳（素材 → skill **引用** `sourceMaterialIds`）+ 版本管理 + 加载接口 + 研究工作台 skill 管理区。

## 定稿约定（plan v2 REV-004 / REV-001）
- skill 条目结构：`{ id, version, title, rule: string, examples?: { bad, good }[], sourceMaterialIds: number[] }`（`rule` = 可执行的规避指令；来源素材可追溯）。
- **载体 = DB 表** `skill_entry`（迁移 v4 已建，见 op-004）；**素材 → skill 以 id 引用**（`source_material_ids_json`），**避免重复存储**。
- 归纳 v0.2 **需人工参与**（不做自动归纳）：用户选素材 + 填 `rule`。
- 版本可管理（`version` 字段）。
