# op-002：多模型无限制创作调度器（采样模式）与素材候选（T1）

- **阶段**：v0.2.0-stage-07

## 目标
实现「多模型无限制创作」采样调度器（**串行逐模型**）+ `MaterialCandidate` 暂存 + 研究工作台模型勾选 UI；采样**不进正文/不自动保存/不触发审查**。

## 定稿约定（plan v2 REV-002）
- **采样「无限制」边界**：不触发自动审查、不自动保存、**上下文无预算裁剪**；产出**仅入素材候选、绝不进编辑器正文/不落 chapter**；研究采样**跳过合规拦截**（样本纯净）。
- **多模型配置来源**：研究工作台列出**全部已配置 `model_config`**，用户**勾选 ≥1**；Key 缺失引导同 stage-05。
- **数据流**：多模型创作产物 → **素材候选（内存 `MaterialCandidate`）** → T2 交叉判断 → T3 用户标注 → material 入库（`status=confirmed`）。
- **调度形态**：**串行逐模型**。
- **落点**：研究工作台 `src/features/research/`（独立路由页）；调度器/契约 `src/orchestration/research/`。
