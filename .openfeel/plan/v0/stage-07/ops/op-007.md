# op-007：闭环回注与度量：skills 注入 + 实验报告（T6）

## 目标
将 skill 规则**回注** stage-05 装配链（`skills` 系统提示注入，缺省向后兼容），并交付**注入前后度量实验**（固定样本集 ≥3 篇、真人感主指标、其余三维不回退超容差）与报告；模块手册登记。

## 跨阶段修改声明（**重要**）
- 本 op **扩展 stage-05 装配器**：`src/orchestration/prompts/chapter-generation.ts` 的 `ChapterPromptInput` 增 **`skills?: { title: string; rule: string }[]`**，`buildChapterPrompt` 将 skill 规则拼入 **system prompt**（预算桶 ≤ 500 字，计入总预算）。
- **向后兼容**：`skills` 缺省/空时行为**完全不变**（系统提示、预算、裁剪顺序均不变）；**stage-05 既有测试（`chapter-generation.test.ts`）必须回归通过**。
- **回写文档**：`.openfeel/manual/features/generation.md`、`.openfeel/manual/orchestration/engine.md` 声明该扩展与兼容性。

## 定稿约定（plan v2 REV-004 / REV-006）
- **两层验证**：单元 = 「注入后 `messages` 含 skill 文本」（可判定单测）；效果 = 注入前后 stage-06 评审总分对比（度量记录）。
- **预算**：skill 段预算桶 **≤ 500 字**并计入总预算。
- **T6 实验**：固定样本集（≥3 篇、每篇 ≥1000 字，入库可复现）；同模型、**温度 = 0**，对「skill 关/开」各评一轮四维分数表；**主指标** = 真人感↑；**约束** = 其余三维不回退超容差；记录落点 `src/features/research/experiments/`；**学术诚实声明**（小样本雏形，非统计显著性）。

## 实施步骤
- [ ] 1. `chapter-generation.ts` 扩展（**向后兼容**）
  ```ts
  export interface PromptSkill { title: string; rule: string; }
  export interface ChapterPromptInput { /* ...既有字段... */ skills?: PromptSkill[]; }
  export const PROMPT_BUDGET = { system: 1000, settingCards: 2000, prevTail: 2000, skills: 500, total: 8000 } as const;
  // buildChapterPrompt：skills 存在时，将「规避要点：\n- rule…」拼入 system 段（≤ skills 预算），并计入 totalLen；
  // 超 total 时沿用裁剪序（设定卡→前文→skill）；skills 缺省时 system/预算/顺序与旧实现一致。
  ```
- [ ] 2. `build-chapter-options.ts`：`buildChapterGenerationOptions` 增可选 `skills?: PromptSkill[]` 透传 `buildChapterPrompt`。
- [ ] 3. `useGeneration.ts`：生成前经 skill 仓储加载 **confirmed skills** → 映射 `{title, rule}` → 传入 options（缺省无 skill 时行为不变）。
- [ ] 4. 回归 + 注入测试（`chapter-generation.test.ts`）
  - **回归**：既有全部用例通过（`skills` 未传时输出与旧实现一致）；
  - **注入（单元可判定）**：传入 skills → `messages[0].content` 含 skill 文本；超出 500 字预算被裁；总预算超额时按序裁剪。
- [ ] 5. 实验（`src/features/research/experiments/`）
  - `samples/`：固定样本集 **≥3 篇、每篇 ≥1000 字**（入库可复现）；
  - `run-experiment.ts`：对每篇用 stage-06 评审管线（同模型、**温度 0**）对「skill 关 / skill 开」各评一轮，汇总**四维分数对比表**；`run-experiment.test.ts` 断言表格结构与「真人感主指标/约束判定」逻辑（假 provider）；
  - `report.md`：**四维对比表** + 实验配置 + **学术诚实声明**（小样本雏形度量，非统计显著性）+ **数据状态字段**（`已回填` / `待回填`）。
  - **实验执行说明（REV-014）**：`run-experiment.ts` 真机执行需真实模型调用（消耗 API 额度），**由用户 / feel-tester 协验执行**（AI 不可替代）。执行者提交时 `report.md` **允许「待回填」占位但必须如实标注数据状态**（空表 + 说明；**严禁占位分数或编造数据**）；真机执行步骤与 `docs/smoke-check-v0.2.md` 的「回注度量」条目**联动**（同一检查单闭环）。
- [ ] 6. 跨阶段文档回写
  - `.openfeel/manual/features/generation.md`：补「`ChapterPromptInput.skills?` 注入（缺省兼容）+ 预算桶 ≤500 字」。
  - `.openfeel/manual/orchestration/engine.md`：补提示模板 `skills` 扩展。

  - `.openfeel/manual/index.md`：登记 `features/research`（研究工作台/采样/标注/素材库/skill/实验）；新增 `.openfeel/manual/features/research.md`。
