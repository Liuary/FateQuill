## 目标
将 skill 规则**回注** stage-05 装配链（`skills` 系统提示注入，缺省向后兼容），并交付**注入前后度量实验**（固定样本集 ≥3 篇、真人感主指标、其余三维不回退超容差）与报告；模块手册登记。

## 跨阶段修改声明（**重要**）
- 本 op **扩展 stage-05 装配器**：`src/orchestration/prompts/chapter-generation.ts` 的 `ChapterPromptInput` 增 **`skills?: { title: string; rule: string }[]`**，`buildChapterPrompt` 将 skill 规则拼入 **system prompt**（预算桶 ≤ 500 字，计入总预算）。
- **向后兼容**：`skills` 缺省/空时行为**完全不变**（系统提示、预算、裁剪顺序均不变）；**stage-05 既有测试（`chapter-generation.test.ts`）必须回归通过**。
- **回写文档**：`.openfeel/manual/features/generation.md`、`.openfeel/manual/orchestration/engine.md` 声明该扩展与兼容性。

## 定稿约定（plan v2 REV-004 / REV-006）
- **两层验证**：单元 = 「注入后 `messages` 含 skill 文本」（可判定单测）；效果 = 注入前后 stage-06 评审总分对比（度量记录）。
- **预算**：skill 段预算桶 **≤ 500 字**并计入总预算。
- **T6 实验**：固定样本集（≥3 篇、每篇 ≥1000 字，入库可复现）；同模型、**温度 = 0**，对「skill 关/开」各评一轮四维分数表；**主指标** = 真人感↑；**约束** = 其余三维不回退超容差；记录落点 `src/features/research/experiments/`；**学术诚实声明**（小样本雏形，非统计显著性）。
