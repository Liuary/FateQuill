- **前置**：op-004（T4 素材库数据层）、op-005（T3 标注）、op-008（交叉判断入口）等已执行产出

- **关联缺陷**：`BUG-001`（medium）——素材库缺读取侧 UI，`export.ts` 三函数与 `material.remove` **生产零调用**，DoD「素材可检索、可导出」界面不可达

## 目标
在 `src/features/research/` 新增**素材库面板**并挂载到 `ResearchWorkbench`：**列表浏览 + 检索（status/source_type/关键字）+ 导出（JSON/CSV）+ 删除（被 skill 引用则提示拒绝）**，使 T4 交付的素材库在 UI 层可达（修复 DoD 第 2 条「可检索、可导出」）。

## 缺陷根因（取证）
- `materialsToJson`/`materialsToCsv`/`downloadExport`（`export.ts`）**仅测试引用**，生产零调用 → 用户无法导出。
- `repositories.material.remove`（含 REV-012 引用防护）**零生产调用** → 删除不可达。
- `material.list` 仅被 `useSkillLibrary` 用于 skill 选材（`{status:"confirmed"}`），**无素材库浏览/检索界面**传递检索条件。
- 研究台仅有 `ResearchWorkbench`/`AnnotationPanel`/`SkillLibrary`，**无素材库组件**。

## 与既有 op / 约束的关系
- **复用**既有 `src/features/research/export.ts`（三函数）、`repositories.material.list/remove`、IPC 命令 `list_materials`/`delete_material`；**不改 Rust / 迁移 / IPC**。
- 仅**新增** `MaterialLibrary.tsx` / `useMaterialLibrary.ts` 并挂载；与 op-004/005/008 产出互补，新增 op-009 编号不冲突。
- 修复后由 openfeel-executor 执行、openfeel-feel-tester 回归复验 BUG-001。

## 实施步骤
- [ ] 1. 新增 `src/features/research/useMaterialLibrary.ts`
  ```ts
  import { useCallback, useEffect, useState } from "react";
  import type { Material, MaterialSourceType, MaterialStatus } from "@/domain/models/material";
  import { IpcError } from "@/ipc/errors";
  import { repositories } from "@/ipc/repositories";

  export interface MaterialFilter { status?: MaterialStatus; sourceType?: MaterialSourceType; query?: string }

  /** 素材库状态：检索（status/sourceType/query）+ 删除（被引用则拒绝提示） */
  export function useMaterialLibrary() {
    const [materials, setMaterials] = useState<Material[]>([]);
    const [state, setState] = useState<"loading" | "ready" | "error">("loading");
    const [actionError, setActionError] = useState<string | null>(null);
    const [filter, setFilter] = useState<MaterialFilter>({});

    const reload = useCallback(async () => {
      setState("loading");
      try { setMaterials(await repositories.material.list(filter)); setState("ready"); }
      catch { setState("error"); }
    }, [filter]);
    useEffect(() => { void reload(); }, [reload]);

    const remove = useCallback(async (id: number) => {
      setActionError(null);
      try { await repositories.material.remove(id); await reload(); return true; }
      catch (e) {
        // 被 skill 引用 → 后端返回 FK_VIOLATION（REV-012）：特异提示
        setActionError(e instanceof IpcError && e.code === "FK_VIOLATION" ? "delete-referenced" : "delete-failed");
        return false;
      }
    }, [reload]);

    return { materials, state, actionError, filter, setFilter, reload, remove };
  }
  ```
