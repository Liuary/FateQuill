# v0.2.0-stage-07 详细计划：去 AI 味研究子系统 v1

## 归属版本
v0.2（质量闭环）

## 目标
把「去 AI 味」建设为**独立可研究、可积累的子系统**：多模型无限制创作 → 多模型交叉判断 + 用户标注 → AI 味素材库 → 规避 skill 库雏形，并回注到创作 Agent。

## 对应核心目的
- 目的 2（第一等公民）：本阶段即该目的的主载体，不可降级为附属功能。

## 前置依赖
v0.1.0-stage-03（多 provider）、v0.2.0-stage-06（评判基础设施）

## 技术约束（本阶段适用）
- 采集通道三路：① 多模型无限制创作；② 多模型交叉判断自动摘取；③ 用户亲自审查/直接指出。
- 素材库**默认仅本地**（已确认 #8），**不做匿名聚合上传**。
- 产出物（规避 skill 库）须以**可被创作 Agent 消费**的结构化形式存在（注入生成提示）。
- 学术性：每次采集需记录判据、来源模型、标注结论，支持导出用于分析。

## 任务表

| # | 任务 | 交付物 | 验收标准 | 依赖 |
|---|------|--------|----------|------|
| T1 | 无限制创作调度器 | 多模型自由创作任务 | 可指定多模型并产出文本（有测试） | stage-03 |
| T2 | 多模型交叉判断摘取 | 交叉评判器 + AI 味片段定位 | 至少 2 模型交叉，输出带定位的 AI 味标注 | T1 |
| T3 | 用户标注工作台 | 标注界面（片段选择 + 理由 + 标签） | 用户可亲自标注 AI 感内容并入库 | stage-06 |
| T4 | AI 味素材库 | 素材 schema + 存储 + 检索 | 素材可入库、检索、导出；含来源与判据 | stage-02 |
| T5 | 规避 skill 库雏形 | 规则/提示片段库 + 版本管理 | 生成 Agent 可加载并在提示中生效（可验证提示变化） | T4 |
| T6 | 闭环回注与度量 | skill 注入到 stage-05 生成 | 注入前后对样本评分可对比（记录度量） | T5,stage-05 |

## 阶段验收标准（DoD）
- [ ] 三条采集通道均可用（多模型创作 / 交叉判断 / 用户标注）。
- [ ] 素材库含来源模型、判据、结论，可检索与导出。
- [ ] 规避 skill 库可被生成 Agent 加载并生效。
- [ ] 有至少一组「注入前/后」的可复现对比度量记录。
- [ ] 素材**默认仅本地**存储，无任何匿名聚合上传（#8 已确认）。

## 风险与备注
- 「AI 味」判据需逐步形式化；v1 以可积累、可对比为先，不追求完备理论。
- 素材库与 skill 库的关系应在设计中明确（素材 → 归纳 → 规则），避免重复存储。
