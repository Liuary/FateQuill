# v0.6.0-stage-12 详细计划：大六壬进阶 + 全自动创作 + 发布打磨

## 归属版本
v0.6（发布打磨）

## 目标
以可选项形式加入大六壬进阶术数；打通无人值守的全自动创作模式；完成开源发布所需文档、许可与打包流程；**英文版（仅界面基本信息）收口**。

## 对应核心目的
- 目的 1：全自动创作满足批量/无人值守创作需求；大六壬提供进阶引导。
- 目的 2：发布使去 AI 味研究成果开源共享，形成社区积累。

## 前置依赖
v0.3.0-stage-09（卦象）、v0.5.0-stage-11（一致性）；软依赖 v0.2.0-stage-07（规避 skill 库）

## 技术约束（本阶段适用）
- 大六壬为**可选进阶**，可关闭，不影响主线；数据来源与许可须合规。
- 全自动创作须串联「推演 → 生成 → 审查 → 重写 → 归档」全链路，并以一致性引擎兜底长程质量。
- 发布：明确开源许可（**MIT，已确认 #2**）；移除任何密钥/私有数据；提供构建与安装说明。
- **i18n 收口**：英文版仅翻译**软件基本信息**（菜单/按钮/设置项等界面文案），**不做内容本地化**；核对全部 UI 文案是否具备 en 文案（缺失回退 zh-CN）。

## 阶段验收标准（DoD）
- [ ] 大六壬可选且不影响主线。
- [ ] 全自动创作可无人值守产出连续多章，且有质量兜底。
- [ ] 仓库含 **LICENSE(MIT)**/README/贡献指南，干净环境可构建。
- [ ] 安全审计通过（无密钥、无隐私外泄、依赖许可兼容 MIT）。
- [ ] 英文版界面基本信息完整（无遗漏英文文案），创作内容保持中文不本地化。
- [ ] 可打 tag 发布正式版本。

## 风险与备注
- 全自动创作的成本与失控风险须有预算与熔断机制。
- 开源许可已定稿为 **MIT**（待确认项 #2 已关闭）；发布前仍须核查第三方依赖与《易经》/大六壬数据资源的许可兼容性。
- 英文版仅覆盖界面基本信息，需在发布前系统扫描遗漏文案，避免中英混杂。
