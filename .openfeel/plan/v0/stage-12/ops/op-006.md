## 目标
完成开源发布工程：`tauri bundle`（**Windows nsis 为主**）+ 干净环境 CI 构建 + **依赖许可清单（工具化）** + Release 流程（版本号三处同步 `v0.6.0`、tag、`CHANGELOG.md`、GitHub Release）。

## 技术依据（plan v2 定稿）
- **打包**：`tauri bundle`；平台清单——**Windows（nsis）为主**，macOS/Linux **显式 best-effort / 不支持**；WebView2 依赖声明（签名留后续）。
- **干净环境可构建**：**CI（GitHub Actions 构建 job）** 为主 + 人工协验声明。
- **依赖许可核查（工具化）**：`license-checker`（npm）+ `cargo license`（Rust）→ **`docs/dependency-licenses.md`** + **MIT 兼容白名单**核查（例外显式登记）。
- **Release 流程**：版本号 **`v0.6.0`**（`package.json` / `src-tauri/tauri.conf.json` / `src-tauri/Cargo.toml` **三处同步**）；git tag `v0.6.0`；产物附 GitHub Release；`CHANGELOG.md`。
- **实测基线**：三处版本均 `0.1.0`；`tauri.conf.json` `bundle.targets="all"`；`.github/workflows/ci.yml` 存在；`CHANGELOG.md` **不存在**。

## 实施步骤
- [ ] 1. **打包配置**：`src-tauri/tauri.conf.json` 的 `bundle`——目标平台收敛为 **`["nsis"]`**（Windows 主）；`targets` 由 `"all"` 改显式平台清单；登记 **WebView2** 依赖说明（安装引导）。
- [ ] 2. **版本同步脚本**：新建 `scripts/sync-version.mjs`（**纯 Node，零依赖**）——将 `package.json` / `src-tauri/tauri.conf.json` / `src-tauri/Cargo.toml` 的 `version` 统一写为目标版本（入参或常量 `0.6.0`）；`package.json` 增 `"version:sync"` 脚本。
- [ ] 3. **许可清单（工具化 + 显式声明 dev 依赖）**：
  - `package.json` **显式新增 devDependency `license-checker`**（**仅 dev，不入 runtime bundle**，此处为「工具化」必需——**唯一新增依赖，已显式声明**）；
  - 新建 `scripts/gen-licenses.mjs`：调 `license-checker`（npm）+ `cargo license`（Rust，如未装则跳过并标注）→ 生成 `docs/dependency-licenses.md`；
  - `docs/dependency-licenses.md`：清单（包/版本/许可）+ **MIT 兼容判定** + **例外清单**（非 MIT 逐一登记理由）；`package.json` 增 `"licenses:gen"` 脚本。
- [ ] 4. **Release 自动化**：新建 `.github/workflows/release.yml`：
  - `workflow_dispatch` + 打 tag 触发；job：`pnpm install --frozen-lockfile` → `pnpm test` → `pnpm lint` → `pnpm build` → `cargo test` → `tauri bundle`（Windows runner）；
  - 产物（nsis 安装包）上传为 Release artifact（`softprops/action-gh-release` 或 `gh`）。
- [ ] 5. **CHANGELOG**：新建 `CHANGELOG.md`（Keep a Changelog 格式；`[0.6.0]` 段：大六壬 / 全自动创作 / 发布工程 / 英文收口；历史 v0.1~v0.5 摘要段落）。
- [ ] 6. **版本号同步**：执行 `scripts/sync-version.mjs` 将三处置 `0.6.0`；提交后打 tag（**由用户在发布时执行**，见备注）。
- [ ] 7. 测试/校验：
  - `scripts/sync-version.test.mjs`（或校验脚本断言）：三处版本一致；
  - `corepack pnpm licenses:gen` 生成 `docs/dependency-licenses.md` 且无未登记非 MIT；
  - `corepack pnpm build` 通过。
- [ ] 8. 校验与提交：
  ```powershell
  corepack pnpm test
  corepack pnpm lint
  corepack pnpm build
  corepack pnpm licenses:gen
  git add -A
  git commit -m "chore(release): bundle config licenses and release flow (T5)"
  ```
