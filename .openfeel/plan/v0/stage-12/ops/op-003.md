# op-003：全自动创作编排：决策规则表与链路（T2）

- **阶段**：v0.6.0-stage-12

- **对应任务**：T2

## 目标
打通**无人值守全自动创作链路**：按**每环节决策规则表**串起「推演 → 生成 → 审查 → 重写 → 降级收录 → 归档」，给定 **≥3 章大纲 → 产出 ≥3 章**（每章 `score ≥ passThreshold` 或标记 `degraded`），**全程零人工交互**。

## 技术依据（plan v2 定稿）
- **每环节自动决策规则表**：
  | 环节 | 规则 |
  |------|------|
  | 推演 | 大纲约束下**多温度择优**（复用 stage-08，取加权总分最高分支） |
  | 生成 | 大纲 + 前置章上下文单次生成（复用 stage-05 装配） |
  | 审查 | 四维阈值（复用 stage-06 `passThreshold`） |
  | 重写 | **≤ N 轮（默认 2，可配）**，注入审查反馈（复用 stage-06 回路） |
  | 仍不达标 | 标记 **`degraded`** + 记录原因，**不阻塞续跑** |
  | 归档 | 每章完成后**自动一致性抽取**（复用 stage-11，候选「自动确认」或待人工按配置） |
- 复用契约：`src/orchestration/{exploration,review,generation,consistency}`（**不重写**）；依赖**可注入**（`streamFor` / 审查器）以便 mock 与真机两条路径。
- **开关状态单源**（kb 收口清单 #4）：进度态落 `autopilotStore`（单例）。
