# op-005：无人值守冲突策略：暂停/授权忽略留痕（T4）

- **阶段**：v0.6.0-stage-12
- **状态**：done
- **前置**：op-003（链路）、op-004（断点/状态）
- **负责 Agent**：openfeel-executor
- **最多重试**：3
- **对应任务**：T4

## 目标
解决「无人值守」×「用户裁决」矛盾：**默认「暂停 + 通知」**（保留用户终裁决）；用户**显式授权**「**自动标记 `ignored` 继续**」——两条路径**均留痕**（`conflict_record`）**可审计**。

## 技术依据（plan v2 定稿）
- 默认「暂停 + 通知」（保留用户终裁决）；
- 显式授权开关「**自动标记 `ignored` 继续**」——冲突按 `ignored` 落 `conflict_record`（**留痕可审计**）；
- 两路径**均留痕**；「自动忽略」仅为**用户显式授权**后的行为（不违背「建议非结论」）。
- 复用：stage-11 `conflict_record`（迁移 v5）+ `runL1Rules`/`runL2` + `resolve_conflict_record`；stage-11 `autopilot` 断点（op-004）实现暂停续跑。

## 实施步骤
- [x] 1. 新建 `src/orchestration/autopilot/conflict-policy.ts`（纯函数）：
  - `decideConflictPolicy({ conflict, pauseOnConflict })` → `{ action: "pause" | "ignore-continue"; record: { aId, bId, type, evidence, severity, status, action } }`；
  - `pauseOnConflict=true`（默认）→ `action:"pause"` + `record.status:"open"`（**留痕**）；
  - `pauseOnConflict=false`（**用户显式授权**）→ `action:"ignore-continue"` + `record.status:"ignored"`、`record.action:"ignore"`（**留痕，可审计**）。
- [x] 2. **链路接入** `src/orchestration/autopilot/chain.ts`：
  - 每章归档后（stage-11 抽取）执行一致性检测 → 得冲突；
  - `decideConflictPolicy` 决策：`pause` → **暂停 run**（`autopilotStore.status="paused"` + 通知）+ **落库**（`save_conflict_record`）；`ignore-continue` → **落库并标记 `ignored`**（`save_conflict_record` + `resolve_conflict_record(action:"ignore")`）后**继续**；
  - 冲突统计并入 `RunOutcome.report`（与 op-004 熔断报告合并）。
- [x] 3. `src/features/autopilot/`：
  - `AutopilotPanel.tsx`：新增「冲突策略」开关（**默认暂停**；勾选=自动 `ignored` 继续，`data-testid="autopilot-auto-ignore"`）+ **暂停通知区**（`data-testid="autopilot-paused"`）；
  - 授权开关状态入 `autopilotStore`（单源）；i18n `autopilot.json` 补 `pauseNotice` / `autoIgnore` / `conflictCount` 文案。
- [x] 4. 测试：
  - `src/orchestration/autopilot/conflict-policy.test.ts`：两路径决策与 `record` 断言（pause→`open`；authorize→`ignored`+`action:ignore`）；
  - `src/orchestration/autopilot/chain.test.ts`（补）：**暂停路径**（默认）→ run 置 `paused` + `save_conflict_record` 被调；**授权路径** → `save_conflict_record` + `resolve_conflict_record(ignore)` 被调且**继续产出后续章**；两路径**均留痕**（mock repo spy）；
  - `src/features/autopilot/AutopilotPanel.test.tsx`（补）：暂停通知渲染 + 授权开关切换。
