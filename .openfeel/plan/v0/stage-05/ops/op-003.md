# op-003：生成入口、生成面板与 generationStore + 流式直插接线（T2、T3）

- **阶段**：v0.1.0-stage-05
- **状态**：pending
- **前置**：op-002（T1 装配）
- **负责 Agent**：openfeel-executor
- **最多重试**：3

## 目标
交付**生成入口 + 生成面板（仅状态）+ `generationStore`（元状态）**，并按 **模式 A 流式直插** 接线：`generationStore` 订阅 stage-03 `subscribeChunks` → 节流 → stage-04 `EditorController.appendChunk`；生成期间编辑器**零 React 重渲染**（C-03，Profiler 断言）。
> 说明（op 合并决策）：T2（入口/面板/store）与 T3（流式直插接线）**强耦合**——T2 的 C-03/Profiler 验收需要真实插入路径，故合并为本 op；两任务交付物分别在下述步骤落实。

## 定稿约定（plan v2 / ADR-002）
- **模式 A**：`generationStore` 订阅 `subscribeChunks` → 节流（`throttleChunks` ≥50ms）→ `EditorController.appendChunk`；**面板仅状态**（进度/停止/重试/错误），**无预览面板**。
- **`generationStore` 边界**：元状态 `status: 'idle'|'streaming'|'done'|'error'|'aborted'` / `chapterId` / `requestId` / `progress:{chars}` / `error:IpcError|null`；**不持正文**；与 `editorStore` **各自独立 `create()`，不互相 setState**。
- **C-03 口径**：流式期间 `editorStore` 除 `saveStatus/lastSavedAt`（自动保存域）外字段不变，且编辑器组件 **React render 计数 = 0**（React `Profiler` 包裹 `EditorContent` 子树断言）。
- **代理指标（T3）**：`dispatch` 次数 ≤ chunk 数 / 2 且**无整文档重设**（无 `setContent` 全量调用）。
- **Key 缺失引导**：无 `model_config` 或 keyring 无 Key → 生成按钮**禁用** + 引导 Settings（i18n 双语）。
- 生成入口 = 工作区**第三栏**（`grid-cols-[280px_1fr_minmax(0,320fr)]`；stage-04 已预留）。
- **requestId 说明（澄清）**：`generationStore.requestId` 为**生成会话关联 id**（`crypto.randomUUID()`，供 UI/日志关联）；底层断流经适配器 `AbortSignal` → `abort_stream`（stage-03 `httpStream` 内部生成 requestId 并返回 abort，前端不直接持有底层 requestId）。

- [ ] 1. 新增 `src/store/generationStore.ts`（**元状态**，独立 `create`）
  ```ts
  import { create } from "zustand";
  import type { IpcError } from "@/ipc/errors";

  export type GenerationStatus = "idle" | "streaming" | "done" | "error" | "aborted";

  interface GenerationState {
    status: GenerationStatus;
    chapterId: number | null;
    requestId: string | null;         // 生成会话关联 id（非底层 requestId）
    progress: { chars: number };
    error: IpcError | null;
    begin: (chapterId: number, requestId: string) => void;
    advance: (chars: number) => void;
    finish: () => void;
    fail: (error: IpcError) => void;
    reset: () => void;                // 半态复位：status=idle、requestId=null、error 保留或清空
  }

  /** 生成元状态（不持正文；正文事实源在 Tiptap 实例）；与 editorStore 独立（C-03） */
  export const useGenerationStore = create<GenerationState>((set) => ({
    status: "idle", chapterId: null, requestId: null, progress: { chars: 0 }, error: null,
    begin: (chapterId, requestId) => set({ status: "streaming", chapterId, requestId, progress: { chars: 0 }, error: null }),
    advance: (chars) => set({ progress: { chars } }),
    finish: () => set({ status: "done" }),
    // 失败/停止后**收敛态 = idle**（DoD：「停止/失败后 status=idle 且无悬挂 requestId」）；error 仅用于展示
    fail: (error) => set({ status: "idle", error, requestId: null }),
    reset: () => set({ status: "idle", requestId: null, error: null }),
  }));
  ```
  > 说明：`status` 枚举保留 `'error'|'aborted'` 供前向兼容，但 v0.1 的**收敛态统一为 `'idle'`**；错误经 `error: IpcError` 展示（不残留 `streaming`/`requestId`）。

- [ ] 4. `src/features/generation/useGeneration.ts`（**模式 A 接线**）
  ```ts
  /** 生成编排：装配 ChatOptions → provider.stream → subscribeChunks → EditorController.appendChunk */
  export function useGeneration(editor: Editor | null) {
    const start = useCallback(async (p: { novelId: number; chapterId: number; userInstruction: string; config: ModelConfig }) => {
      if (!editor) return;
      const options = await buildChapterGenerationOptions({ novelId: p.novelId, chapterId: p.chapterId, userInstruction: p.userInstruction, model: p.config.modelName, temperature: p.config.temperature });
      const provider = resolveProviderForConfig(p.config);
      const abort = new AbortController(); abortRef.current = abort;
      const controller = createEditorController(editor);
      const g = useGenerationStore.getState();
      g.begin(p.chapterId, crypto.randomUUID());
      let chars = 0;
      try {
        const source = provider.stream({ ...options, signal: abort.signal });
        for await (const chunk of subscribeChunks(source)) {         // stage-03 节流(≥50ms)
          if (abort.signal.aborted) break;
          controller.appendChunk(chunk.delta);                        // stage-04 直插（恒入历史/合并）
          chars += chunk.delta.length; g.advance(chars);
        }
        controller.flushPending();
        if (!abort.signal.aborted) g.finish();
      } catch (e) {
        controller.flushPending();
        g.fail(parseIpcError(e));
      } finally {
        controller.dispose();
        abortRef.current = null;
      }
    }, [editor]);
    const stop = useCallback(() => { abortRef.current?.abort(); }, []);
    return { start, stop };
  }
  ```
  > 注：**不修改** stage-04 `useChunkInjection`/`EditorController` 内部（C-09）；本 op 用其**公开 API**（`createEditorController`）+ stage-03 `subscribeChunks` 实现接线。
