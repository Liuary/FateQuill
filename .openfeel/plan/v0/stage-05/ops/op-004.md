# op-004：停止/失败处置与生成状态机（T4）

- **阶段**：v0.1.0-stage-05
- **状态**：pending
- **前置**：op-003（T2+T3 生成接线）
- **负责 Agent**：openfeel-executor
- **最多重试**：3

## 目标
完善生成的状态机：用户「停止」或流式错误时，**已插入内容保留为草稿**、`generationStore` 收敛为 **`idle` 且无悬挂 `requestId`**、错误经 `IpcError` 提示；用户一次 `Ctrl+Z` 可撤销整段生成；UI 明示停止语义。

## 定稿约定（plan v2 REV-006）
- **停止/失败后**：已插入内容**保留**（草稿语义，用户可 `Ctrl+Z` 或手动删除）；`generationStore` 收敛 `status='idle'`、`requestId=null`（**无半态**）；错误经 `IpcError` 提示。
- **「半态」定义**：`generationStore` 残留 `streaming` 状态 / 悬挂 `abort` 句柄 / 非空 `requestId`。**状态机复位断言入测试**。
- **撤销**：由 stage-04 `EditorController`（`newGroupDelay=5000` 会话合并）承担 —— **一次 `Ctrl+Z` 撤销整段生成**；本阶段不重复实现。
- **UI 明示**：停止后提示「生成已停止，可 Ctrl+Z 撤销」（i18n 双语），避免用户困惑。
