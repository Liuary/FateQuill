# op-002：生成请求装配：上下文预算与提示模板（T1）

- **阶段**：v0.1.0-stage-05
- **状态**：pending
- **前置**：op-001
- **负责 Agent**：openfeel-executor
- **最多重试**：3

## 目标
实现生成请求装配：从作品/章/设定卡与前章末尾构建上下文，按定稿预算裁剪，产出 **provider 无关的 `ChatOptions`**；提示模板落点 `src/orchestration/prompts/chapter-generation.ts`（**版本化**，为 stage-07 skill 注入预留）。

## 定稿约定（plan v2 REV-004）
- **装配产物 = `ChatOptions`**（`model` / `messages` / `temperature`）；**provider 差异由 stage-03 适配器吸收**，装配器**不感知 provider 语义**。
- **预算**：系统提示 ≤ **1000** 字 + 设定卡 ≤ **2000** 字 + 前章末尾 ≤ **2000** 字 + 用户指令（**优先保留，不裁**）；**总 ≤ 8000** 字。
- **裁剪序**：超限按「**设定卡 → 前文**」裁剪（系统提示与用户指令**不裁**）。
- 前情策略（v0.1 无摘要）：取**前章（order_index 紧邻上一章）末尾 M 字**。
- 模板版本常量 `CHAPTER_GENERATION_PROMPT_VERSION`；模板函数纯 TS、可单测。

## 涉及文件/目录
- 新增：`src/orchestration/prompts/chapter-generation.ts`、`src/orchestration/prompts/index.ts`
- 新增：`src/features/generation/build-chapter-options.ts`（数据装配：仓储 → `ChapterPromptInput` → `ChatOptions`）

  ```ts
    model: string;
    temperature?: number;
  }

  /** 各源裁剪：设定卡按序累计至 ≤ settingCards 预算；前文取末尾 ≤ prevTail 预算；合计超 total 时按「设定卡→前文」继续裁 */

  ```
  - `buildChapterPrompt` 逻辑要点：
    1. `system` = `slice(systemPrompt, 0, budget.system)`；`instruction` = `userInstruction`（**不裁**）。
    2. 设定卡：按数组顺序拼接 `标题: 内容`，累计至 ≤ `budget.settingCards`；超出则截断（记录丢弃数）。
    3. 前文：`tail = previousChapterTail.slice(-budget.prevTail)`（末尾 M 字）。
    4. 合计 = `system + settings + tail + instruction`；若 > `budget.total`：**先削设定卡**（可清空），仍超**再削前文**（可清空）；系统与指令保持。
    5. 返回 `{ model, temperature, messages: [{role:"system",content:system}, {role:"user",content:[settings, tail, instruction].filter(Boolean).join("\n\n")}] }`。
