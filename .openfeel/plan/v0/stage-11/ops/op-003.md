# op-003：自动归档抽取器（evidence 回查 + 名称去重）（T2）

- **阶段**：v0.5.0-stage-11
- **状态**：done
- **前置**：op-002（tier 模型）
- **负责 Agent**：openfeel-executor
- **最多重试**：3
- **对应任务**：T2

## 目标
实现**手动「归档本章」**的 LLM 抽取器：输出 `{name, kind, suggestedTier, content, evidence}`；**`evidence` 原文回查**（防幻觉）；**名称精确去重**；候选入**会话内存待确认队列**（不入库直达），用户确认后经 **`save_extracted_settings`** 批量落库。

## 技术依据（plan v2 定稿）
- 抽取 = **LLM + 白文依据**：`evidence` 为**原文逐字片段**供回查（复用 stage-08 存在性校验范式）。
- 去重 = **名称精确匹配既有卡**（别名/语义相似**留后续**，v0.5 局限声明）。
- 触发 = **手动「归档本章」按钮**（用户主导；自动钩子留拍板）。
- 产出 = **候选列表**（不入库直达，逐条确认/修正分级后入库）。

## 实施步骤
- [x] 1. 新建 `src/orchestration/consistency/types.ts`：`ExtractedSetting { name; kind; suggestedTier: SettingCardTier; content; evidence }`、`ExtractionCandidate = ExtractedSetting & { status: "new"|"duplicate"; evidenceVerified: boolean }`。
- [x] 2. 新建 `src/orchestration/consistency/extract.ts`：
  - `EXTRACTION_SYSTEM_PROMPT`（JSON 输出契约：`{ settings: [{name,kind,suggestedTier,content,evidence}] }`）；
  - `buildExtractOptions({ chapterText, modelRef })` → `ChatOptions`；
  - `parseExtraction(text)`：JSON 容错（**复用 `@/orchestration/review/json` 的 `extractJson`**）；非法/缺字段候选**丢弃**；
  - `verifyEvidence(candidate, chapterText)`：规范化空白后断言 `evidence` 为 `chapterText` **子串**——不满足则**剔除**（防幻觉硬闸）。
- [x] 3. 新建 `src/orchestration/consistency/dedupe.ts`：`dedupeByName(candidates, existingNames)`：名称**精确匹配** → `status:"duplicate"`（**不重复建卡**）；否则 `"new"`。
- [x] 4. 新建 `src/orchestration/consistency/run.ts`：`runExtraction({ chapterText, existingNames, modelRef, streamFor, signal })`：非流式收口 → `parseExtraction` → `verifyEvidence`（剔除）→ `dedupeByName`；**返回契约定稿**（REV-008②）：`{ ok: boolean; candidates: ExtractionCandidate[]; error?: string }`——收口/解析异常 → `{ ok:false, candidates: [], error: <msg> }`（**失败不抛穿**）；成功但零命中 → `{ ok:true, candidates: [] }`（合法空态）；`ArchivePanel` 据 `ok/error` 呈现失败提示（i18n `consistency.extractFailed`），据 `candidates.length===0` 呈现空态。
- [x] 5. **待确认队列（会话内存）**：新建 `src/store/archiveStore.ts`（独立 `create`）：`candidates`、`setCandidates`、`updateCandidate(index, patch)`（修正 `suggestedTier`/`content`）、`removeCandidate(index)`、`clear`；**不落库**。
- [x] 6. **归档批量落库 IPC（新增 1 命令）**：`save_extracted_settings`（`src-tauri/src/commands.rs` + `db/setting_card.rs`）：入参 `{ novelId, items: [{ title, content, kind, tier }] }`，**事务内批创建**；加入 `lib.rs` 的 `generate_handler!`；`src/ipc/repositories/setting-card-repository.ts` 增 `saveExtracted(novelId, items)`。**本 op 与实现同提交更新 `docs/ipc.md` 计数**：§8.1 `45 → 46`；全仓（§8.1 + §6 流式 2）`47 → 48`（**双口径见 op-001/§8**；op-005 续 `46→51` / `48→53`）。
