## 目标
实现**两级一致性校验**：**L1 规则**（结构化冲突，**零幻觉/零成本**）+ **L2 语义**（LLM 判定，**建议非结论**），产出**结构化冲突报告** `{aId,bId,type,evidence,severity}`；并以**≥3 章预埋冲突标注样本集**验收**误报率 ≤ X%**（X 待拍板，默认 0.2）。

## 技术依据（plan v2 定稿）
- L1 = 结构化冲突（同名实体属性表比对：**生死 / 时间线 / 数值**前后矛盾）——**可判定、零成本、零幻觉**。
- L2 = LLM 判定「新设定是否与 `main`/`dark` 矛盾」→ `{verdict, reason, evidence}`，**标注为建议、非结论**。
- 报告结构：`{ 冲突设定对(aId,bId), 冲突类型(type), 依据原文(evidence), 严重度(severity) }`。
- 阈值：标注样本集**人工标注误报率 ≤ X%**（X 待拍板，建议 ≤20%）；「20 章长程」**降级**为后续持续收集。
- 与 stage-06 边界：**一致性=设定内冲突（设定 vs 设定）**；世界观评审=正文 vs 设定（**op-001 已登记**）。

## 困难点与决策
- **L1 对自由文本的可判定性**：设定卡为自由文本，无结构化属性列。**决策**：L1 采用**保守正则抽取 + 同名实体比对**，仅在「同实体、同属性、明确矛盾」时报出（宁缺毋滥以压误报）；结构化程度不足的语义矛盾**交 L2**。**备选**：为卡引入属性 JSON 列——**本阶段不采纳**（避免扩迁移范围，C-08）。
- **误报率阈值 X**：**未拍板**。**决策**：以常量 `MISREPORT_THRESHOLD = 0.2` 占位（建议默认），在「前置」声明该偏差；用户拍板后调整常量。
