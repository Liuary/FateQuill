# op-008：修复归档面板与 tier 表单生产不可达（BUG-001）(fix)

- **阶段**：v0.5.0-stage-11
- **状态**：done
- **前置**：op-003（归档抽取/落库）、op-005（一致性 tab）
- **负责 Agent**：openfeel-executor
- **最多重试**：3
- **关联缺陷**：`BUG-001`（**high**）——`ArchivePanel` **未接入任何 UI**，`runExtraction`/`save_extracted_settings` **生产零调用**；`SettingCardForm` **无 `tier` 字段** → DoD 1「新设定可手动归档并分入四级」应用内**完全不可达**

## 目标
使**手动归档 → 待确认队列 → 确认入库（含 tier）**与**设定卡四级选择**在应用中**生产可达**：`consistency` tab 同时挂载 `ArchivePanel`；`SettingCardForm` 增 `tier` 四级下拉。

## 缺陷根因（取证）
- `src/features/editor/WorkspaceLayout.tsx` L165-167：`consistency` 分支**仅**渲染 `<ConsistencyPanel novelId={currentNovelId} />`，**无 `ArchivePanel`**（`rg "ArchivePanel" src` 仅命中自身 + 单测）。
- `src/features/consistency/useArchiveChapter.ts`：`runExtraction`（L46）、`saveExtracted`（L84，经 `repositories.settingCard.saveExtracted` → `save_extracted_settings`）**生产零调用**（`ArchivePanel` 未被挂载）。
- `src/features/setting-cards/SettingCardForm.tsx` L20-22/L45-53：仅 `title`/`kind`/`content`，**无 `tier`**；`SettingCardInput`（`useSettingCards.ts` L5-9）**无 `tier`**。
- `op-005` 修正记录 #11 曾声明「`ArchivePanel` 的 tab 接入随本 op 一并可用」——实际未落地（声明与实现不符）。
- 已就绪（无需新依赖）：`SETTING_CARD_TIERS`/`DEFAULT_SETTING_CARD_TIER`（`src/domain/models/setting-card.ts`）、`repositories.settingCard.create/update` 已支持 `tier?`、`consistency.json` 已含 `tier.*` 文案。

## 方案（最小接入）
- **`consistency` tab 双区渲染**：`ArchivePanel`（归档区）+ `ConsistencyPanel`（冲突区）**同 tab 上下排列**（归档在上），二者均生产可达。**备选**：子 tab（归档/冲突）——**不采纳**（多一份 tab 状态，最小接入优先）。
- **`SettingCardForm` 增 `tier` 四级下拉**（复用 `SETTING_CARD_TIERS`），提交贯通 `create`/`update`。
