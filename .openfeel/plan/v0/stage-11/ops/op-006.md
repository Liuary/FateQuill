## 目标
在**装载侧**实现分级注入：白名单 `tier ∈ {main, short}`、**排除 `dark`**（硬隔离）；注入开关可对照；**预算不变**；单测断言「开 → prompt 含 main/short 且**不含 dark**；关 → 与基线一致」。

## 技术依据（plan v2 定稿）
- 注入白名单：`tier ∈ { main, short }` 且**排除 `dark`**——暗线**仅入一致性校验与作者侧面板**；实现为**装载侧过滤**。
- 预算关系：分级**不改 `PROMPT_BUDGET` 结构**；筛选在装载侧，超预算按既有裁剪序。
- 与 stage-10 契约：装载侧过滤，**契约签名不变或以可选参数扩展**（不回改 stage-10）。
- 对比验证：**单测级**（注入开关 → 含/不含断言，同 stage-09 `hexagramGuide` 范式）+ 效果级（可选，样本对照入库 `src/features/research/experiments/`，**标注非统计显著性**）。
- **实测装载点**：`src/features/exploration/build-exploration-options.ts` L38-40、`src/features/generation/build-chapter-options.ts`、`src/features/dialogue/scene-context.ts`（settingCards 装载）。

## 困难点与决策
- **「关 → 与基线一致」的语义歧义**：若「关」= 回退 v0.4 行为（注入**全部**设定卡），将**泄露 `dark`**，与 DoD「暗线不注入」**冲突**。**决策（安全优先）**：生产**恒排除 `dark`**（硬要求，无开关可绕过）；「注入开关」定义为「**是否注入设定卡**」——开 = 注入 `{main,short}`，关 = **完全不注入**（得纯净基线）。**备选**（否决）：关=旧全量行为——因 `dark` 泄露事故（剧透）**否决**。
