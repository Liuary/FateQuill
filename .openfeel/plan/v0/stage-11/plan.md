# v0.5.0-stage-11 详细计划：设定分级归档与一致性引擎

> 修订：v2（2026-10-10，依据 REV-v0.5.0-stage-11 的 6 条审查意见按 v2 范式重写）。

## 归属版本
v0.5（一致性）

## 目标
让作品在长程创作中保持设定自洽：新设定**手动触发归档并分级**，既有设定约束被遵守，**冲突可检出、可处置**，且**分级影响注入与暗线保密**。

## 对应核心目的
- 目的 1：解决长篇创作最痛的「前后设定打架」问题。
- 目的 2：一致性提升文本可信度，是「人味」的结构性基础。

## 前置依赖与遗留处置
- v0.1.0-stage-05（生成产物）、v0.4.0-stage-10（角色设定 / persona 契约）——硬依赖。
- **遗留处置（修订 REV-006④）**：
  - **stage-10 REV-007（low，台词评审维度子集）**：**归属 stage-12 或人工协验批处理**（与本阶段无耦合），本阶段仅登记归属。
  - **stage-08 REV-009（次路径快照=会话内存级 → 持久化路线）与迁移 v5 联动决策（定稿）**：**v5 不纳入版本池快照持久化**——v5 仅服务本阶段（`setting_card.tier` + `conflict_record`）；两域不同（review 版本池 vs 设定冲突），保持克制（C-08），REV-009 仍独立跟踪。
  - v0.2~v0.4 人工协验 **BLOCKED**（真实 Key E2E / 真机 WebView / 台词评审语义符合度 / T6 实验回填 / perf）：保持跟踪、不阻塞本阶段。

## 技术约束（本阶段适用，定稿）

### 分级模型（定稿，修订 REV-001）——四级定义 + 正交关系 + 持久化
- **四级定义表**（判定标准 / 生命周期 / 冲突严格度）：

  | tier | 语义 | 生命周期 | 冲突严格度 |
  |------|------|----------|------------|
  | **`main` 主线** | 贯穿全书的核心约定 | 长期；转正后永久 | **硬约束必须遵守** |
  | **`dark` 暗线** | 隐藏设定（未揭示） | 长期隐藏；揭晓后可转主线 | 硬约束，且**不注入正文** |
  | **`short` 短线** | 近期章节有效的设定 | 近章生效；可**转正**或**过期** | 软约束（近章生效） |
  | **`temp` 临时** | 一次性/局部细节 | 可**丢弃/过期** | 仅提示 |

- **与 `SettingCard.kind` 正交（澄清）**：`kind` = **内容类型**（`general`/`fate`/`character`/`settingCard`，已建立），`tier` = **叙事层级**——**两维独立**（一个「角色」kind 的卡可为 `main` 或 `temp`）；**不扩 kind 值域**。
- **持久化（定稿）**：**迁移 v5** `ALTER TABLE setting_card ADD COLUMN tier TEXT NOT NULL DEFAULT 'short'`（默认**短线保守**）；理由：tier 过滤在 **SQL 层**（优于 JSON 扫描查询代价）。
- **与 stage-10 契约衔接**：分级过滤发生在**装载侧**（`buildChapterPrompt` / `buildExplorationOptions` / `buildCharacterAgentPrompt` 的设定卡装载按 tier 过滤），**契约签名不变或以可选参数扩展**（不回改 stage-10）。
- **可判定验收**：四级归档/查询/过滤单测；**迁移幂等**（表数 **9→10**、`tier` 列存在断言）。

### 自动归档抽取器（定稿，修订 REV-002）
- **方式**：**LLM 抽取 + 白文依据**——输出 `{ name, kind, suggestedTier, content, evidence }`；**`evidence` 为原文逐字片段供回查**（复用 stage-08 存在性校验范式，防幻觉）。
- **新设定去重**：**名称精确匹配既有卡**（别名/语义相似**留后续**，v0.5 显式声明局限）。
- **触发**：**手动「归档本章」按钮**（用户主导，同「克制」哲学；自动钩子留拍板）。
- **产出**：**候选设定列表**（**不入库直达**，用户逐条确认/修正分级后入库——复用 stage-08「待确认队列」范式）。
- **可判定验收**：样本章节（入库 ≥1 篇，含已知实体）→ mock/真模型抽取 → 断言**已知实体被抽出**且 `evidence` 为**原文子串** + **去重不重复建卡**。

### 一致性引擎（定稿，修订 REV-003）——两级校验 + 冲突报告 + 可判定阈值
- **两级校验（分工定稿）**：
  - **L1 规则校验**：结构化冲突（同名实体属性表比对：生死/时间线/数值前后矛盾）——**可判定、零成本、零幻觉**；
  - **L2 语义校验**：LLM 判定「新设定是否与 `main`/`dark` 矛盾」，输出 `{ verdict, reason, evidence }`，**标注为建议、非结论**。
- **冲突报告结构**：`{ 冲突设定对(aId,bId), 冲突类型(type), 依据原文(evidence), 严重度(severity) }`。
- **DoD 可判定化（修订原「≥20 章」条款）**：
  - **阈值显式约定**：样本集上**人工标注误报率 ≤ X%**（X 列入「待用户拍板」，建议 ≤ 20%）；
  - **长程样本方案**：v0.5 自建 **≥3 章含预埋冲突的标注样本集**入库（复用 stage-08 T6 样本范式）；**「20 章长程验证」降级为「后续持续收集 / 用户作品协验」**（避免不可承受的样本成本）。
- **与 stage-06 评审边界（切分）**：**一致性引擎 = 设定库内冲突（设定 vs 设定）**；**四维评审「世界观」= 正文 vs 设定（文本质量）**——职责登记同一 rubric 引用，互不重复。

### 注入策略与暗线保密（定稿，修订 REV-004）
- **注入白名单**：`tier ∈ { main, short }` 且**排除 `dark`**——**暗线仅入一致性校验与作者侧面板**；实现为**装载侧过滤**（同 REV-001③ 同点）。
- **预算关系**：分级**不改变 `PROMPT_BUDGET` 结构**；注入筛选在装载侧完成，超预算仍按既有裁剪序。
- **对比验证**：**单测级**（注入开关 → prompt 含/不含设定文本断言，同 stage-09 `hexagramGuide` 范式）+ **效果级**（可选：样本章节注入前后对照入库 `src/features/research/experiments/`，同 stage-08 T6 范式，**标注非统计显著性**）。
- **可判定验收**：注入开 → prompt **含主线/短线设定文本且不含暗线内容**（断言）；关 → 与基线一致。

### 冲突处置与 IPC / 持久化（定稿，修订 REV-005）
- **处置动作集**：`{ 修改分级, 编辑设定卡（**跳转编辑器 + verbatim 定位**）, 标记误报（反馈闭环保留）, 忽略（留痕） }`。
- **持久化**：抽取候选 = **会话内存待确认队列**（同 stage-08 范式）；冲突记录 = **落库**（跨会话留痛，**迁移 v5 一并设计** → `conflict_record`）。
- **IPC 增量**（据实盘点并入 `docs/ipc.md` 计数）：新增归档抽取命令 + 冲突 CRUD（`list/get/resolve/ignore` 类），命名与计数由 schemer 定稿。
- **冲突面板落点**：`src/features/consistency/`（或设定卡面板内嵌冲突区，由 schemer 细化）。

### 结构与可判定（定稿，修订 REV-006）
- **C-07**：任务表含「交付物路径 + 可判定验证标准」两列。
- **C-11（i18n）**：启用 **`consistency`** 命名空间（归档/冲突面板文案 zh-CN/en）；`setting_card` tier 标签复用 settings 域。
- **文档回写**：`docs/structure.md`（`src/orchestration/consistency/`、`src/features/consistency/` 落点）、`docs/ipc.md`（命令计数更新）、`docs/review-rubric.md`（一致性 vs 世界观边界）、`manual/index.md`（登记 consistency 模块）。

## 风险与备注
- **语义一致性易误报**：L2 仅作**建议**（非结论）；阈值 + 人工复核通道；分级严格度可配置。
- **暗线泄露=剧透事故（硬要求）**：`dark` 注入白名单硬隔离（装载侧），**仅入一致性引擎与作者视图**；以断言守护。
- **抽取幻觉**：`evidence` 原文回查（stage-08 先例）拦截不存在实体；名称去重 v0.5 仅精确匹配（局限声明）。
- **样本成本**：「20 章长程」不可承受 → 降级为 ≥3 章预埋冲突标注样本集 + 后续持续收集。
- **迁移 v5 范围克制**：仅 `tier` 列 + `conflict_record`；**不含** stage-08 REV-009 版本池快照持久化（独立跟踪）。
- **与 stage-10 契约**：不修改 persona 契约签名（倾向可选参数扩展），避免回改。

## 待用户拍板（建议默认值）
1. **误报率阈值 X**：建议 **≤ 20%**（标注样本集口径）。
2. **样本规模**：建议 **≥3 章预埋冲突标注样本集**（20 章长程降级为后续持续收集）。
3. **持久化方案**：建议**迁移 v5**（`tier` 加列 + `conflict_record`），而非 JSON。
4. **抽取触发时机**：建议**手动「归档本章」**（自动钩子留后续）。
5. **暗线注入边界**：建议 `dark` **完全排除正文注入**（仅一致性引擎 + 作者视图）。
