# v0.4.0-stage-10 详细计划：角色 Agent 多声部对话

## 归属版本
v0.4（多声部）

## 目标
把「一个 Agent 写全文」升级为「旁白 Agent + 每角色独立 Agent」的多声部协作，并支持旁白/对话分离创作与合并。

## 对应核心目的
- 目的 1：增强角色区分度与对白真实感。
- 目的 2：多声部天然抵抗「千人一腔」的 AI 味，服务去 AI 味目标。

## 前置依赖
v0.1.0-stage-03（引擎）、v0.1.0-stage-05（生成闭环）；软依赖 v0.5.0-stage-11（角色设定供给）

## 技术约束（本阶段适用）
- 每个主要角色 = 一个 Agent（persona 来自角色设定/生平），注册到编排引擎。
- 旁白与对话**分离生成**，可分别编辑与合并；合并结果保持格式一致。
- 角色 Agent 之间不共享私有上下文，只共享公共场景上下文（防串味）。
- 角色数量增长时的并发与成本需可控。

## 任务表

| # | 任务 | 交付物 | 验收标准 | 依赖 |
|---|------|--------|----------|------|
| T1 | 角色 Agent 生成器 | 由角色设定创建 Agent（persona 提示） | 每个角色可生成符合人设的台词（测试） | stage-03 |
| T2 | 旁白/对话分离创作 | 分离的生成面板与编辑流 | 旁白与对话可分别生成、分别编辑 | stage-05 |
| T3 | 多声部合并 | 合并器 + 格式规范 | 合并后格式统一、顺序正确（测试） | T2 |
| T4 | 角色设定管理 | 角色 CRUD + 生平字段 | 角色设定可持久化并被其 Agent 引用 | stage-02 |
| T5 | 上下文隔离 | 角色上下文装配策略 | 角色只获公共场景上下文，测试无串味 | T1 |

## 阶段验收标准（DoD）
- [ ] 每个主要角色可创建独立 Agent 并生成差异化台词。
- [ ] 旁白/对话可分离创作与编辑，合并格式正确。
- [ ] 角色上下文隔离可验证。
- [ ] 角色设定持久化并驱动其 Agent。

## 风险与备注
- 「千人一腔」的判定与 stage-06/07 的真人感判据应互认。
- 角色数多时并发成本高，须提供并发上限与「仅主要角色」开关。
