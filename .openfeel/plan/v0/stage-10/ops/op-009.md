# op-009：修复多声部生产装配未含设定卡/前文/场景指令（BUG-001）(fix)

- **阶段**：v0.4.0-stage-10
- **状态**：done
- **前置**：op-003（生成接线）、op-006（`context.buildPublicContext`）
- **负责 Agent**：openfeel-executor
- **最多重试**：3
- **关联缺陷**：`BUG-001`（medium）——生产 `useDialogue.buildPublicContext` 仅为 op-003 最小接线，**op-006 的完整 `context.buildPublicContext` 生产零调用**，场景上下文仅落地「公共对话历史」1/4

## 目标
把生产装配从「最小接线」替换为 **op-006 完整装配**：装载**设定卡** + **前章末尾/当前章正文** + **用户场景指令** + **公共对话历史**四块，经 `@/orchestration/dialogue/context` 的 `buildPublicContext` **单源**产出；面板补「场景指令」输入。

## 缺陷根因（取证）
- `src/features/dialogue/useDialogue.ts` L41-48：本地 `buildPublicContext` 仅将 `dialogueStore.entries` 拼接为文本，**不读设定卡 / 章节正文 / 场景指令**。
- `src/orchestration/dialogue/context.ts` L37 `buildPublicContext({ settingCards, previousChapterTail, sceneInstruction, history })`（四块）**生产零调用**（`rg` 仅命中 `context.test.ts` 与 `index.ts`）。
- `src/features/dialogue/DialoguePanel.tsx` L139-289：**无场景指令输入控件**、**不加载设定卡/章节**。
- `src/locales/zh-CN/dialogue.json`：**无场景指令键**。
- 边界：`context.buildPublicContext` 与 `useDialogue` 内**同名**最小实现**重名**（BUG-001「边界」注记），须统一为**单源**。

## 方案（生产接线完整装配 + 消除重名）
- **单源**：删除 `useDialogue` 内本地最小 `buildPublicContext`，改调 `context.buildPublicContext`。
- **上下文装载**：新增 `useSceneContext`（`src/features/dialogue/`）装载设定卡与前章末尾；场景指令为面板会话态输入。
- **复用既有 IPC**：设定卡 `repositories.settingCard.listByNovel`；章节 `repositories.chapter.get` + `listByVolume`（**复用 `build-exploration-options.ts` L42-51 取「前章末尾」逻辑**）。**零新增依赖 / 无迁移 / 无 IPC 增量**。
