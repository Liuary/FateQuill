# op-006：上下文隔离（防串味）装配（T5）

- **阶段**：v0.4.0-stage-10
- **状态**：done
- **前置**：op-002（persona 契约）
- **负责 Agent**：openfeel-executor
- **最多重试**：3
- **对应任务**：T5

## 目标
固化**上下文白名单**装配，实现**防串味**可判定：每个角色 Agent 输入 = **本人 persona（完整）** + **公共场景** + **公共对话历史**，**不含他人 persona 全文**（仅**公开身份一行摘要**）；单测断言「角色 A 秘密 X」**不出现在角色 B 的 prompt**。

## 技术依据（plan v2 定稿）
- 可共享：场景设定、已定稿对话（`{speaker, content}`）、旁白、他人**公开身份一行摘要**。
- 私有（不共享）：他人 persona 细节、内心独白、秘密。
- 串味判据（可判定）：构造「角色 A persona 含秘密 `X`」→ 断言**角色 B 的 prompt 不含 `X`**（装配层）。

## 实施步骤
- [x] 1. 新建 `src/orchestration/dialogue/context.ts`：
  - `buildPublicContext({ settingCards, previousChapterTail, sceneInstruction, history })`：**公共场景上下文**（设定卡 + 前章末尾/当前章 + 用户场景指令 + 公共对话历史 `[{ speaker, content }]`）——**不含任何他人 persona**；
  - `buildPublicSummary(profile)`：由 `profile` 仅取 `identity`（缺省→角色名）生成**公开身份一行摘要**；
  - `buildCharacterAgentInput({ selfProfile, publicContext, others })`：输出 `{ system, user }`——system=本人 persona 完整（经 `buildCharacterAgentPrompt`）；user=公共上下文 + 他人摘要（`他人（公开身份）：{summary}` 行）；**不含他人 persona 细节**。
- [x] 2. `generate.ts`（op-003）接线：生成角色台词时**只**传入 `buildCharacterAgentInput(...)`，杜绝直接传入全量角色列表。
- [x] 3. 测试 `src/orchestration/dialogue/context.test.ts`：
  - **串味断言（核心）**：构造角色 A `profile.personality` 含秘密字串 `X="月蚀之夜弑父"`，角色 B 无此内容 → `buildCharacterAgentInput({ selfProfile: B, publicContext, others: [A] })` 的 `system+user` **不含 `X`**；
  - **摘要断言**：B 输入**含**他人 A 的公开身份**一行摘要**（`A.identity`），但**不含** A 的 `personality/speechStyle` 私有细节；
  - **公共要素断言**：B 输入**含**公共场景（设定卡文本/前章末尾/场景指令）与公共对话历史（第三方已说台词）；
  - **白名单穷举**：随机注入多角色，断言仅 self persona 全文被包含。
- [x] 4. 校验与提交：
  ```powershell
  corepack pnpm test -- dialogue/context
  corepack pnpm lint
  corepack pnpm build
  git add -A
  git commit -m "feat(dialogue): context whitelist to prevent persona bleed (T5)"
  ```
