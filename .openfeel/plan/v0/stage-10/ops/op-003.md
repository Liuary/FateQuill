# op-003：旁白/对话分离创作与 dialogueStore（T2）

- **阶段**：v0.4.0-stage-10
- **状态**：done
- **前置**：op-002（persona 契约与 Agent 注册）
- **负责 Agent**：openfeel-executor
- **最多重试**：3
- **对应任务**：T2

## 目标
落地**会话内存**产物容器 `dialogueStore`（条目增删改/排序）与**旁白 / 对话分离生成面板**：旁白与角色台词**可分别生成、分别编辑**；轮次**用户主导**（选中角色 → 生成 → 追加历史 → 可反复）。

## 技术依据（plan v2 定稿）
- 条目结构：`{ id, kind: "dialogue"|"narration", speakerId?, speakerName?, content, orderIndex }`（**会话内存** store，同 stage-08 `explorationStore` 范式，独立 `create()`）。
- 顺序来源：`orderIndex`（UI 可上移/下移/插入）。
- 复用：`src/orchestration/stream`（`subscribeChunks`）与 stage-03 provider（`resolve-provider.ts` 范式）做非流式收口。

## 实施步骤
- [x] 1. 新建 `src/store/dialogueStore.ts`（**会话内存，独立 `create`**）：
  - 状态：`entries: DialogueEntry[]`、`running: boolean`；
  - 动作：`addEntry(entry)`（自动分配 `orderIndex`=末尾+1）、`insertAt(index, entry)`（后续 `orderIndex` 重排连续）、`updateEntry(id, patch)`、`removeEntry(id)`（重排）、`moveEntry(id, dir: -1|1)`（相邻交换并重排）、`setRunning(v)`、`clear()`（清条目，保持空）；
  - `DialogueEntry` 类型定义于 `src/orchestration/dialogue/types.ts`（与 store 共用）。
- [x] 2. 新建 `src/orchestration/dialogue/generate.ts`：
  - `generateLine({ options, streamFor })`：**非流式收口**（聚合 `Chunk.delta` 全文），失败**不抛穿**（返回 `{ ok, text?, error? }`）；
  - `toCharacterOptions({ profile, publicContext, modelRef, temperature })`：经 `buildCharacterAgentPrompt` 构造 `ChatOptions`（system=persona+公共上下文）。
- [x] 3. 新建 `src/features/dialogue/`：
  - `useDialogue.ts`：编排 `generateNarration()` / `generateCharacterLine(character)`（经 `useCharacters`/仓储取 profile → `registerCharacterAgent` → `generateLine` → `addEntry`）；持 `AbortController` 支持停止。
  - `DialogueEntryList.tsx`：条目列表渲染（`dialogue` 显示 `speakerName：content`；`narration` 显示正文）+ **行内编辑** + 上移/下移/删除/插入。
  - `NarrationComposer.tsx` / `CharacterLineComposer.tsx`：分别触发旁白 / 角色台词生成（**分离入口**）。
  - `DialoguePanel.tsx`：装配以上（旁白区 + 对话区 + 公共历史视图）。
- [x] 4. i18n：新增 `src/locales/{zh-CN,en}/dialogue.json`；`src/app/i18n.ts` 注册 `dialogue` 命名空间；
- [x] 5. `WorkspaceLayout.tsx` 第三栏新增 tab `dialogue`（`"generation"|"settingCards"|"review"|"exploration"|"dialogue"`，渲染 `DialoguePanel`）。
- [x] 6. 测试：
  - `src/store/dialogueStore.test.ts`：CRUD + `orderIndex` **连续**断言（增删/移动/插入后 `entries.map(e=>e.orderIndex)` 恒为 `0..n-1`）；
  - `src/orchestration/dialogue/generate.test.ts`：假 `streamFor` → 收口全文；失败分支返回 `ok:false` 且不抛；
  - `src/features/dialogue/DialoguePanel.test.tsx`：旁白与对话**可分别生成、分别编辑**；条目增删改可判定。
- [x] 7. 校验与提交：
  ```powershell
  corepack pnpm test
  corepack pnpm lint
  corepack pnpm build
  git add -A
  git commit -m "feat(dialogue): separate narration/character composition with dialogueStore (T2)"
  ```
