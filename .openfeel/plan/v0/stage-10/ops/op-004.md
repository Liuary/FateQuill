# op-004：多声部合并与落章双路径（T3）

- **阶段**：v0.4.0-stage-10
- **状态**：pending
- **前置**：op-003（dialogueStore）
- **负责 Agent**：openfeel-executor
- **最多重试**：3
- **对应任务**：T3

## 目标
实现**条目 → HTML 的合并器**（按 `orderIndex` 拼接、格式统一）与**双路径落章**：主路径「新建下一章草稿」无损；次路径「替换当前章」**确认 + 强制快照 + 单次撤销**（复用 stage-08 REV-007 安全网范式）。

## 技术依据（plan v2 定稿）
- 格式规范（**单一规范，样式由 CSS 承担**）：对话 `<p class="dialogue"><strong>{speakerName}</strong>：{content}</p>`；旁白 `<p class="narration">{content}</p>`。
- 双路径（复用 `src/features/exploration/useAdoptBranch.ts` 先例）：
  - 主路径 = `chapter.create`（追加当前卷末，**不改当前章**）；
  - 次路径 = `EditorController.replaceContent`（**单条撤销**）+ **强制入池快照**（`reviewStore.addVersion`）。

## 实施步骤
- [ ] 1. 新建 `src/orchestration/dialogue/assemble.ts`：
  - `assembleDialogueHtml(entries)`：**按 `orderIndex` 升序**拼接；`dialogue` → `<p class="dialogue"><strong>{esc(speakerName)}</strong>：{esc(content)}</p>`；`narration` → `<p class="narration">{esc(content)}</p>`；
  - `esc()`：HTML 转义 `& < > " '`（防注入）；
  - 空 `entries` → 返回空串。
- [ ] 2. 新建 `src/features/dialogue/useMergeDialogue.ts`（双路径编排）：
  - `mergeAsNextChapter(currentChapterId)`（**主路径**）：取当前章 `volumeId`，`orderIndex = max(同卷)+1`，`repositories.chapter.create({ volumeId, title: t("nextChapterTitle"), content: assembleDialogueHtml(entries), contentFormat: "html", orderIndex })`；**不改当前章**；成功后可选 `clear()`；
  - `replaceCurrentChapter(currentChapterId, currentHtml)`（**次路径，危险**）：
    1. **UI 二次确认**（调用方 `ConfirmInline` 范式）；
    2. **强制入池快照（必做，非可选）**：`reviewStore.getState().addVersion({ id: crypto.randomUUID(), label: "dialogue-merge-safety", content: currentHtml, round: -1, results: {} })`；
    3. `createEditorController(editor).replaceContent(assembleDialogueHtml(entries))`（单条撤销）→ `dispose()`；
  - 返回 `{ ok: boolean }`。
- [ ] 3. `DialoguePanel.tsx` 接入合并按钮（主/次路径 + 次路径确认），i18n `dialogue.json` 补 `merge` / `mergeNextChapter` / `mergeReplace` / `mergeConfirm` 文案。
- [ ] 4. 测试：
  - `src/orchestration/dialogue/assemble.test.ts`：乱序 `entries` → **按 `orderIndex` 拼接正确**；`dialogue`/`narration` 格式断言；`esc` 转义断言；
  - `src/features/dialogue/useMergeDialogue.test.ts`：
    - 主路径：mock `chapter.create` → 断言 `content=拼接`、`volumeId`/`orderIndex` 正确、**当前章无 `update`**；
    - 次路径：mock `editor` + `reviewStore` → 断言**先 `addVersion`（快照）后 `replaceContent`**、快照 `content=替换前正文`、`replaceContent` 恰调用一次。
- [ ] 5. 校验与提交：

  corepack pnpm build
