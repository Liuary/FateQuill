# op-005：角色管理面板与 profile 字段约定（T4）

- **阶段**：v0.4.0-stage-10
- **状态**：pending

- **负责 Agent**：openfeel-executor

## 目标
建立**角色管理面板**（CRUD，复用既有 character 命令）与 `profile` 最小字段约定的**表单落地**：角色设定**持久化**并**驱动其 Agent**（`profile` 字段被对应 Agent 引用）。

## 技术依据（plan v2 定稿）
- 零迁移：`character.profile` 为 **JSON**（最小字段 `{ identity, personality, speechStyle, goal, extra, major? }`）。
- 复用既有 IPC 命令（**无增量**）：`list_characters` / `get_character` / `create_character` / `update_character` / `delete_character`（`docs/ipc.md` L101 已登记）；仓储接口 `src/domain/repositories/character-repository.ts`（`listByNovel/get/create/update/remove`）。
- CRUD UI 落点：`src/features/characters/`。

## 实施步骤
- [ ] 1. 新建 `src/orchestration/dialogue/profile.ts`：
  - 从 `types.ts` 的 `CHARACTER_PROFILE_KEYS` 导出 `DialogueProfile` 校验/归一函数 `normalizeProfile(raw: Record<string, unknown>): DialogueProfile`（缺失→空串，`major`→boolean，**异常安全**）；
  - 供 `buildCharacterAgentPrompt`（op-002）与 `CharacterForm`（本 op）**共用同一字段来源**。
- [ ] 2. 新建 `src/features/characters/`：

  - `CharacterForm.tsx`：字段 `identity / personality / speechStyle / goal / extra`（文本）+ `major`（勾选）→ 组装 `profile` JSON；`onSubmit` 走 create/update；
  - `CharactersPanel.tsx`：列表 + 新增/编辑/删除（`ConfirmInline` 范式）。
- [ ] 3. i18n：新增 `src/locales/{zh-CN,en}/characters.json`；`src/app/i18n.ts` 注册 `characters` 命名空间。

- [ ] 5. 测试：
  - `src/features/characters/useCharacters.test.ts`：mock `repositories.character` → CRUD 调用与列表刷新断言；`profile` 归一（`major` 布尔、缺失字段→空串）；
  - `src/orchestration/dialogue/profile.test.ts`：`normalizeProfile` 边界（`null`/缺字段/非布尔 `major`）；
  - **契约一致性断言**：`CharacterForm` 提交的 `profile` 经 `buildCharacterAgentPrompt` 后，`identity/speechStyle` **出现在 system**（表单字段 ↔ Agent 引用同源）。
