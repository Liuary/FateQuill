## 目标
建立**角色管理面板**（CRUD，复用既有 character 命令）与 `profile` 最小字段约定的**表单落地**：角色设定**持久化**并**驱动其 Agent**（`profile` 字段被对应 Agent 引用）。

## 技术依据（plan v2 定稿）
- 零迁移：`character.profile` 为 **JSON**（最小字段 `{ identity, personality, speechStyle, goal, extra, major? }`）。
- 复用既有 IPC 命令（**无增量**）：`list_characters` / `get_character` / `create_character` / `update_character` / `delete_character`（`docs/ipc.md` L101 已登记）；仓储接口 `src/domain/repositories/character-repository.ts`（`listByNovel/get/create/update/remove`）。
- CRUD UI 落点：`src/features/characters/`。
