# op-002：角色 Agent 生成器与 persona 契约（T1）

- **阶段**：v0.4.0-stage-10
- **状态**：done
- **前置**：op-001（首个 op）
- **负责 Agent**：openfeel-executor
- **最多重试**：3
- **对应任务**：T1

## 目标
建立多声部生成底座：定稿 **persona 装配输入契约**（`buildCharacterAgentPrompt`）与**角色/旁白 Agent 注册**，persona 关键要素**注入断言**可判定，生成器**可注册/可替换**。

## 技术依据（plan v2 定稿）
- persona 契约：`character.profile` 为 **JSON**（零迁移），最小字段 `{ identity, personality, speechStyle, goal, extra, major? }`（自由文本；`major: boolean` 供「仅主要角色」过滤）。
- 模板：`buildCharacterAgentPrompt(profile, 公共上下文)`（persona **完整注入本人 Agent**）；**旁白 Agent** = 叙述者 persona + 同装配链，**仅 system 差异**。
- 复用 `src/orchestration/registry.ts`（`Registry<T>` 的 `register/replace`）与 `types.ts`（`Agent`/`ModelRef`）。

## 实施步骤
- [x] 1. 新建 `src/orchestration/dialogue/types.ts`：
  - `DialogueProfile { identity?; personality?; speechStyle?; goal?; extra?; major?: boolean }`（全字段可选，**缺失安全降级**）；
  - `DialogueAgentInput { profile; publicContext; modelRef; }`；
  - `CHARACTER_PROFILE_KEYS`（字段名常量，供 T4 表单与装配共用同一来源）。
- [x] 2. 新建 `src/orchestration/dialogue/persona.ts`：
  - `readProfileField(profile, key)`（缺省→空串，异常安全）；
  - `buildCharacterAgentPrompt({ profile, publicContext })`：**system 段**含 persona 全要素（`identity/personality/speechStyle/goal/extra`，跳过空字段），**user 段**含公共上下文；
  - `buildNarratorAgentPrompt(publicContext)`：叙述者 persona，**与角色 Agent 仅 system 差异**。
- [x] 3. 新建 `src/orchestration/dialogue/agents.ts`：
  - `registerCharacterAgent(reg, { id, name, modelRef, profile, publicContext })` → 构造 `Agent`（`systemPrompt = buildCharacterAgentPrompt(...).system`），经 `reg.agents.register/replace`（**可替换**）；
  - `registerNarratorAgent(reg, { modelRef, publicContext })` → 叙述者 `Agent`。
- [x] 4. 新建 `src/orchestration/dialogue/index.ts`（`export *` 汇总）。
- [x] 5. 测试 `src/orchestration/dialogue/persona.test.ts`：
  - **persona 注入断言**：给定含 `identity="侠客甲"`、`speechStyle="冷峻寡言"` 的 profile → 生成 `system` **包含**两要素；空 profile → 不抛错、字段降级为空；
  - **旁白差异断言**：角色 Agent 与旁白 Agent `system` **不同**、装配链一致（同装配函数）；
  - **注册/替换断言**：`registerCharacterAgent` 两次同 id → 第二次 `replace` 覆盖（不抛重复 id），`reg.agents.resolve(id).systemPrompt` 反映最新 persona。
- [x] 6. 校验与提交：
  ```powershell
  corepack pnpm test -- dialogue/persona
  corepack pnpm lint
  corepack pnpm build
  git add -A
  git commit -m "feat(dialogue): character agent personas and registry (T1)"
  ```
