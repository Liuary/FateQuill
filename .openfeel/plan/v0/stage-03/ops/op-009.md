## 变更目标

**A. 设置页布局对齐**
1. `section` 改为可读容器：`mx-auto flex w-full max-w-3xl flex-col gap-4 p-6`（**居中 + 统一内边距**，与 header 观感一致）。
2. 标题与按钮**同一行**：`<div className="flex items-center justify-between">` 包 `<h2 className="text-xl font-semibold">{t("title")}</h2>` 与「新增模型配置」按钮（去掉单独 `justify-end` 一行）。
3. **表单 / 列表逻辑不变**（仅容器与标题行结构调整）。

**B. 补齐 provider 预设**（均 `openai-compatible`，`baseUrl` / 模型名**均可在表单中修改**）
- 新增 `gemini`（Google Gemini）/ `grok`（xAI Grok）/ `ernie`（百度文心一言 千帆）/ `hunyuan`（腾讯混元）/ `spark`（讯飞星火）/ `doubao`（字节豆包 火山方舟，**无默认模型**）。
- 顺序按可读分组：**OpenAI → Anthropic → Gemini → Grok → DeepSeek → 智谱 → 通义 → Kimi → 文心 → 混元 → 星火 → 豆包 → 硅基流动 → MiniMax → 自定义**（共 **15** 项）。
- 文件头注释注明：**baseUrl / 模型名以各厂商官方文档为准，可在表单中修改**。
