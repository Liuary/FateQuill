# op-008：设置页模型配置支持国内 provider 预设与自定义入口 (feat)

- **阶段**：v0.3.0-stage-03（模型配置；用户报告改进）
- **状态**：done
- **前置**：stage-03 模型配置（`model_config` + keyring，已归档）
- **负责 Agent**：openfeel-executor
- **最多重试**：3
- **用户诉求**：`ModelConfigForm` 的 provider 下拉**硬编码仅 `["openai-compatible","anthropic"]`**，缺国内主流 provider 预设与自定义入口（**功能上国内厂商已可用**——`resolve-provider` 对非 anthropic 一律走 OpenAI 兼容适配器——但无预设、需手填 baseUrl/model）。

## 变更目标

1. **新增预设清单** `src/domain/models/provider-presets.ts`：`ProviderPreset { id; name; adapter: "openai-compatible" | "anthropic"; baseUrl; defaultModel? }` + `PROVIDER_PRESETS`（**9 项**：`openai` / `anthropic` / `deepseek` / `zhipu` / `qwen` / `moonshot` / `siliconflow` / `minimax` / `custom`）+ 反查工具（`findPreset` / `isPresetId`）。
2. **`ModelConfigForm` 改造**：下拉渲染预设（`value = preset.id`，`label = preset.name`）；选择预设时**自动填充 `baseUrl` 与 `modelName`**（`defaultModel` 存在时；字段**保持可编辑**）；选 `custom` → 提供 **provider id 文本输入**（自定义 id）+ baseUrl 文本输入；**编辑既有配置**时按 `initial.provider` **反查选中预设**，未命中 → 视为自定义并回填该 id。
3. **契约不变**：`onSubmit(ModelConfigCreateInput)` 与 `keyringSet(provider, label, apiKey)` 不变（仅新增可选的 `providerId` 输入用于 custom）。
4. **不新增依赖**；**不跑 `cargo test`**（`tauri dev` 运行中）。

## 涉及文件

- 新建：`.openfeel/plan/v0/stage-03/ops/op-008.md`（本文件）、`src/domain/models/provider-presets.ts`、`src/features/settings/ModelConfigForm.test.tsx`
- 修改：`src/features/settings/ModelConfigForm.tsx`、`src/locales/{zh-CN,en}/settings.json`（新增 `providerId` 标签；**en 同步**以满足 i18n 键完整性）
