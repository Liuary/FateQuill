# op-002：起卦与朱熹变爻推导（T2）

- **阶段**：v0.3.0-stage-09
- **状态**：pending
- **前置**：op-001（T1 数据）
- **负责 Agent**：openfeel-executor
- **最多重试**：3

## 目标
实现起卦与取卦：**朱熹《易学启蒙》变爻规则**纯函数 `deriveHexagram`（0~6 七情形）+ 起卦两法（**随机=可注入随机源、支持种子复现**；**手动=指定卦/变爻**）+ 起卦 UI（**时间起卦入口不呈现**）。

## 定稿约定（plan v2 REV-002）
- **变爻规则（朱熹，七情形）**：0 爻变看本卦卦辞；1 爻变看本卦变爻辞；2 爻变看本卦二变爻辞（以**上爻**为主）；3 爻变看本卦与之卦卦辞；4 爻变看之卦二不变爻辞（以**下爻**为主）；5 爻变看之卦不变爻辞；6 爻变看之卦卦辞。
- **起卦**：随机 = **可注入随机源**（测试确定性/种子复现）；手动 = 直接指定卦 + 可选指定变爻；**时间起卦（农历/干支）v0.3 不呈现**（不引入历法依赖，C-08）。
- **纯函数**：`deriveHexagram(lines) → { benGua, zhiGua, changingLines }`。
- **落点**：算法 `src/orchestration/iching/`；起卦 UI `src/features/exploration/`。
- **i18n**：启用 `iching` 命名空间（**卦辞经文本身不译**）。
