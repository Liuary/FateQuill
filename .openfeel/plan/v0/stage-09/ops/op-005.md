## 目标
将卦象引导**可选**接入 stage-08 推演装配：`buildExplorationOptions` 增可选参数 `hexagramGuide?`（开启时并入 **system 约束段**，缺省**完全不影响**）；交付推演面板内**开关**（缺省关闭，`localStorage` 持久化）；保证**关闭零副作用**且 `converge` 行为不变。

## 定稿约定（plan v2 REV-003）与**跨阶段修改声明**
- **跨阶段修改**：扩展 stage-08 `src/features/exploration/build-exploration-options.ts`——增 **`hexagramGuide?: { text: string }`**；开启时并入 **system 段**；**缺省/未传时输出与基线逐字段一致**（与 stage-05 `skills?` 同范式，向后兼容）。
- **注入点**：卦象引导并入推演 system 约束段（**不修改 `intent`/user 段**）。
- **收敛联动**：卦象引导**不进入 `converge` 的设定卡覆盖判据**（设定卡最高优先）；偏离仍按 stage-08 标注。
- **开关**：推演面板内开关；**缺省关闭**；`localStorage['fatequill.iching.enabled']`；不做强制前置。
- **回写**：`.openfeel/manual/features/exploration.md`（声明 `hexagramGuide?` 扩展与兼容性）。
- **可判定验收**：关闭时输出与基线一致 + 卦象模块零调用；开启时 system 段含卦象文本 + `converge` 行为不变。
